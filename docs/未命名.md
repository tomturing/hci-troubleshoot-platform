## 前置检查：
 1、告警硬盘是否系统盘
 ```
 lsblk | grep boot | grep -q "${disk_sn}" && echo "true" || echo "false"
 ```
 返回为true跳转【系统盘寿命异常】，返回为false跳转【aSAN盘寿命异常】
## 系统盘寿命异常

### 前置检查：
1、系统盘${disk_sn}是否为软RAID阵列盘：
- 若回显包含 `sdX`（如 `sda1`），则盘符为 `sda`。跳转【非软RAID阵列盘】
- 若回显包含 `mdX`（如 `md0`），则表示系统盘为软 RAID 阵列。跳转【软RAID阵列盘】

### 软RAID阵列盘
#### 判断方法
1、查看软RAID阵列盘有哪些成员盘及其盘符
```bash
mdadm --detail /dev/${disk_sn}   # mdX 为上一步获取的软 RAID 盘符
```

回显中带有 `sd` 前缀的设备即为实际盘符（如 `sdb`）。
2、获取SMART信息（不清楚告警系统盘具体指向哪个成员盘情况下，成员盘的SMART信息都需要获取）
```bash
smartctl -a /dev/sdX   # sdX 为步骤1获取的盘符
```

- 若提示 `Error smartctl args: '-a'`，请改用：

    ```bash
    smartctl.real -a /dev/sdX   # sdX 为步骤1获取的盘符
    ```
3、从 SMART 信息中提取以下字段：`Device Model`、`Model Number`、`Product`，根据厂商型号前缀匹配跳转【硬盘厂商识别与寿命判断】

### 非软RAID阵列盘
#### 判断方法
1、获取SMART信息
```bash
smartctl -a /dev/sdX   # sdX 为步骤1获取的盘符
```

- 若提示 `Error smartctl args: '-a'`，请改用：
    ```bash
    smartctl.real -a /dev/sdX   # sdX 为步骤1获取的盘符
    ```
- 若提示 `device lacks SMART capability`，则可能为硬件 RAID 环境，则跳转【硬件RAID阵列盘】
2、从 SMART 信息中提取以下字段：`Device Model`、`Model Number`、`Product`，根据厂商型号前缀匹配跳转【硬盘厂商识别与寿命判断】

## 硬件RAID阵列盘
### 变量声明
| 变量名      | 类型     | 来源      | 说明   |
| -------- | ------ | ------- | ---- |
| disk_dev | string | context | 前序动作 |
### 前置检查
1、确认 RAID 卡类型

```bash
lspci | grep -i "controller:" | egrep -i "raid|sas" | grep -v "Volume Management Device"
```

示例回显：

```
0000:18:00.0 Serial Attached SCSI controller: Broadcom / LSI SAS3008 PCI-Express Fusion-MPT SAS-3 (rev 02)
```

### MegaRAID 卡（如 SAS 9361-8i、INSPUR 3008IMR 等）
#### 判断方法

1、查看虚拟磁盘
    
    ```bash
    storcli64 /c0/vall show
    ```

2、查看物理成员盘，根据 {disk_sn}确认对应的DID
    
    ```bash
    storcli64 /c0/v1 show PDs   # 查看 VD1 的成员盘
    ```
    
3、查看物理盘 SMART，下面的sdX盘符即变量{disk_dev}
    
    ```bash
    smartctl -a -d megaraid,<DID> /dev/sdX   # 如 smartctl -a -d megaraid,5 /dev/sda
    ```
- 若提示 `Error smartctl args: '-a'`，请改用：
    
    ```bash
    smartctl.real -a -d megaraid,<DID> /dev/sdX
    ```
4、从 SMART 信息中提取以下字段：`Device Model`、`Model Number`、`Product`，根据厂商型号前缀匹配跳转【硬盘厂商识别与寿命判断】

### SAS RAID 卡（如 SAS3008、SAS9311-8i）
#### 判断方法

1、查看虚拟磁盘
    
    ```bash
    sas3ircu 0 display | grep -A15 "IR Volume Information"
    ```
    
2、查看 by-path 设备
    
    ```bash
    ls -l /dev/disk/by-path/
    ```
    
3、查看物理盘 SAS Address
    
    ```bash
    sas3ircu 0 display | grep -A10 "Device is a Hard disk"
    ```
    
4、建立映射表（示例）

| RAID 类型 | Encl:Slot | SAS Address      | sg设备     | sn  |
| ------- | --------- | ---------------- | -------- | --- |
| RAID1   | 1:0       | 500605b001234567 | /dev/sg0 | xxx |
| RAID1   | 1:1       | 500605b001234568 | /dev/sg1 | xxx |
| RAID0   | 1:2       | 500605b001234569 | /dev/sg2 | xxx |

5、查看物理盘 SMART，根据 {disk_sn}确认对应的sg设备路径
    
    ```bash
    smartctl -a /dev/sgX
    ```
- 若提示 `Error smartctl args: '-a'`，请改用：
    
    ```bash
    smartctl.real -a -d megaraid,<DID> /dev/sdX
    ```
6、从 SMART 信息中提取以下字段：`Device Model`、`Model Number`、`Product`，根据厂商型号前缀匹配跳转【硬盘厂商识别与寿命判断】

## 硬盘厂商识别与寿命判断
### 前置检查
1. **型号前缀**：`kcm*`、`kpm*`、`krm*`、`kcd*`、`kxd*`、`kfl*`、`klc*`、`khk*`、`*kioxia*`、`*toshiba*`跳转【Kioxia / Toshiba（铠侠 / 东芝）】
2. **型号前缀**：`ssdsc*`、`ssdpe*`、`ssdpf*`、`mdtpe*`、`*intel*`跳转【Intel（英特尔）】
3. **型号前缀**：`mz*`、`*samsung*`跳转【Samsung（三星）】
4. **型号前缀**：`mtfd*`、`*micron*`跳转【Micron（美光）】
5. **型号前缀**：`ts*`、`*transcend*`跳转【Transcend（创见）】
6. **型号前缀**：`hs-ssd*`、`*hikvision*`跳转【Hikvision（海康）】
7. **型号前缀**：`sts*`、`dts*`、`datssd*`跳转【大唐存储】
8. **型号前缀**：`hwe*`、`hssd*`、`*huawei*`跳转【Huawei（华为）】
9. **型号前缀**：`rsye*`、`*longsys*`跳转【Longsys（江波龙）】
10. **型号前缀**：`fi*`、`*foresee*`跳转【Foresee】
11. **型号前缀**：`liteon*`、`*ssstc*`跳转【Liteon / SSSTC（建兴）】

### Kioxia / Toshiba（铠侠 / 东芝）
#### 判断方法
1. **判断说明**：SMART 第 173 项的 `VALUE` 字段，默认值为 200。当 `VALUE` 小于 100 时，建议返修。

### Intel（英特尔）

#### 判断方法
1. **判断说明**：SMART 第 233 项的 `VALUE` 字段，默认值为 100。当 `VALUE` 小于或等于 10 时，建议返修。

### Samsung（三星）

#### 判断方法
1. **判断说明**：SMART 第 177 项的 `VALUE` 字段，默认值为 100。当 `VALUE` 小于或等于 10 时，建议返修。

### Micron（美光）

#### 判断方法
1. **判断说明**：SMART 第 202 项的 `VALUE` 字段，默认值为 100。当 `VALUE` 小于或等于 10 时，建议返修。

### Transcend（创见）

#### 判断方法
1. **判断说明**：SMART 第 167 项的 `RAW_VALUE` 字段，默认值为 0。当 `RAW_VALUE` 大于或等于 2700 时，建议返修。

### Hikvision（海康）

#### 判断方法
1. **判断说明**：SMART 第 233 项的 `RAW_VALUE` 字段，默认值为 0。当 `RAW_VALUE` 大于或等于 90 时，建议返修。

### 大唐存储

#### 判断方法
1. **判断说明**：SMART 第 233 项的 `VALUE` 字段，默认值为 100。当 `VALUE` 小于或等于 10 时，建议返修。

### Huawei（华为）

#### 判断方法
1. **判断说明**：SMART 第 231 项的 `VALUE` 字段，默认值为 100。当 `VALUE` 小于或等于 10 时，建议返修。

### Longsys（江波龙）

#### 判断方法
1. **判断说明**：SMART 第 202 项的 `VALUE` 字段，默认值为 100。当 `VALUE` 小于或等于 10 时，建议返修。

###  Foresee

#### 判断方法
1. **判断说明**：SMART 第 167 项的 `RAW_VALUE` 字段，默认值为 0。当 `RAW_VALUE` 大于或等于 2700 时，建议返修。

### Liteon / SSSTC（建兴）

#### 判断方法
1. **判断说明**：优先使用 SMART 第 202 项的 `VALUE` 字段，默认值为 100，当 `VALUE` 小于或等于 10 时建议返修。若无 202 项，则参考第 177 项。
