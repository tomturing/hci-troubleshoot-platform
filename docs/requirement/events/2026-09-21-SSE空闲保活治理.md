# 需求：SSE 空闲保活治理

- 来源工单：Q2026092130181（诊断进行中浏览器报 network error，提示"执行流已结束，但未收到对应的执行结果"）。
- 根因：长耗时诊断（动态 skill 非流式 LLM 调用 120s×N 重试）期间 SSE 无字节输出，触发反向代理
  `proxy_read_timeout=300s` 掐断连接。
- 目标：
  1. 治本：长耗时诊断期间 SSE 连接不被代理空闲掐断（注入心跳字节）。
  2. 可观测：心跳活动可计数、可查日志。
  3. 体验：网络中断时前端给出可重试提示，而非沉默失败。
- 非目标：不修改 LLM 读超时默认值（心跳已从根因解耦；LLM 超时收敛作为独立议题）。
- 约束：心跳必须为 SSE 注释行（`:` 开头），不得进入业务事件、不得污染前端 content；
  心跳间隔须远小于代理空闲超时（默认 20s）。
