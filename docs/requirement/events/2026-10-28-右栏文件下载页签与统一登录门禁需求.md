# 右栏「文件下载」页签化与统一登录门禁需求

## 变更历史

| 日期 | 版本 | 变更内容 | 关联事件文档 |
|------|------|---------|------------|
| 2026-10-28 | v1.0 | 初版：SSH 登录成功弹框去重勾；文件下载从终端底部提为右栏独立页签，未登录先走统一登录框 | [SSH 终端 SFTP 文件下载方案](../../solution/custom-ui/events/2026-10-27-SSH终端SFTP文件下载方案.md) |

## 背景

Custom UI 现场截图暴露两处问题：

1. 从 SSH 终端点击登录、连接成功后，弹框里同时出现**两个勾**：一个绿色实心勾（24px 状态图标）与文字前的一个灰色线性勾。两个图标表达同一件事，用户第一反应是「是不是还有一步没完成」。
2. 「文件下载」被做成 SSH 终端底部的 24px 折叠条（`文件下载 从远端主机下载到本机`）。它是一块需要浏览目录、看进度、核对落地路径的独立工作区，挤在终端下方既看不见列表，又把终端高度压掉一条。

用户要求：左栏保持「日志收集 + 历史工单」两个抽屉，右栏拆成「SSH 终端 + 文件下载」两个抽屉；且文件下载必须先判断 SSH 是否已登录，未登录时提示登录。

## 需求

### R1 登录成功态只保留一个图标

- 成功态只能有一个状态图标；保留带语义色（绿）的实心勾，删除文字旁的灰色同义勾。
- 成功文案必须说清"打开的是哪一块面板"：终端页签为「SSH 连接成功，终端已打开」，文件下载页签为「SSH 连接成功，文件下载已打开」。

### R2 文件下载成为右栏独立页签

- 右栏两个入口平分一块面板位置：`SSH 终端` / `文件下载`，折叠态各有一个图标按钮，展开后标题随页签切换。
- 切换页签**不得**销毁 xterm 实例、不得断开 SSH 会话（两者共用同一条会话）。
- 原终端底部的折叠条移除，文件下载面板占满右栏主体，目录列表自己滚动。

### R3 未登录先登录，且复用同一套登录模板

- 未登录时点击「文件下载」入口：不打开面板，直接弹**与 SSH 终端完全相同**的登录弹框（`SshConnectSection`），不新增第二套表单。
- 登录成功后自动落到「文件下载」页签，不能把用户丢回终端页。
- 取消登录 / 登录失败必须清掉"登录后去文件下载"的意图，避免之后任意一次登录都莫名跳页签。
- 进入页签后会话掉线：页签内只给「连接 SSH」按钮，点击仍走同一个登录门禁。

## 验收标准

| 编号 | 场景 | 期望 |
|------|------|------|
| AC-1 | 登录成功 | 弹框内只有一个绿色勾 + 一句成功文案 |
| AC-2 | 未登录点「文件下载」 | 面板不打开，弹出 SSH 登录弹框（标题「连接 SSH 终端」），无第二套表单 |
| AC-3 | 上一步登录成功后 | 右栏展开且停在「文件下载」页签，并自动列出远端默认目录 |
| AC-4 | 已登录点「文件下载」 | 直接切到「文件下载」页签，不弹框 |
| AC-5 | 页签来回切换 | SSH 会话不断开，终端历史输出仍在；切回终端后列宽正确（重新 fit） |
| AC-6 | 取消登录后再登录 | 落在「SSH 终端」页签（挂起意图已清空） |
| AC-7 | 会话掉线 | 文件下载页签内显示登录引导，点击复用同一登录弹框 |

## 非目标

- 不改 SFTP 协议与 bridge 侧落盘逻辑（见 [SSH 终端 SFTP 文件下载方案](../../solution/custom-ui/events/2026-10-27-SSH终端SFTP文件下载方案.md)）。
- 不提供远程文件管理（删除/改名/上传），面板仍是只读下载器。
- 不为文件下载单独做一套 SSH 表单。
