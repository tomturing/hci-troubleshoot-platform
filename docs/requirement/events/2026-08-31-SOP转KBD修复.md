# 工单 Q2026083135310：SOP 未解决后转入 KBD

## 问题

同一故障分类同时存在已发布 SOP 和 KBD 时，用户在 S6 选择“未解决”并回退到 S1，下一轮仍按“SOP 优先”重新进入原 SOP，KBD 分支不可达。

## 修复

- S6 “未解决”在同一数据库事务中将当前 `sop_execution` 标记为 `aborted`，清理待填变量。
- 会话服务向 Agent 传递该终态；Agent 只对 `active/interrupted` SOP 做恢复，对 `aborted` SOP 设置本会话 KBD 回退标记。
- KBD 候选仍从 S0 确认分类的完整快照加载，仅切换轨道，不改变候选集合边界。

## 验证

- 增加回归测试：同分类同时有 SOP/KBD 且 SOP 已 `aborted` 时，Agent 不产生 `sop_reasoning`，进入 KBD 诊断并保留候选快照审计字段。
