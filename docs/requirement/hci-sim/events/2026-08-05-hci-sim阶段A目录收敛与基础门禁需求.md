# hci-sim 阶段 A：目录收敛与基础门禁需求

## 1. 背景

仓库同时存在 `hci_sim/` 和 `hci-sim/` 两套 Go SSH 仿真实现。正式 CI、K3s 构建、Helm、历史 Golden E2E 和项目规范使用 `hci_sim/`；`hci-sim/` 是后续重复合入的简化 Spike。双实现会造成修复分叉、测试覆盖错觉、构建入口不一致和安全策略降级风险。

本阶段只解决“唯一代码基线”和“后续演进不能退化”两个问题，不扩展多 KBD 能力。

## 2. 用户与用户故事

| 用户 | 用户故事 |
|---|---|
| 开发者 | 我希望仓库只有一个 hci-sim 源码入口，避免修错目录或重复实现能力。 |
| 测试者 | 我希望 PR 自动运行正确目录的单测、race、vet、build 和 Manifest 校验。 |
| 运维人员 | 我希望二进制、镜像、Chart、Service 与源码目录的命名规则明确且可追溯。 |
| 安全审查者 | 我希望旧实现的任意密码、可选 Lease 和模糊路由不能被重新引入。 |

## 3. 功能需求

### A-FR-01 唯一源码基线

- 唯一源码目录必须为 `hci_sim/`。
- 二进制、镜像、Helm Chart、Deployment 和 Service 对外名称继续使用 `hci-sim`。
- 删除 `hci-sim/` 前，必须完成有价值行为清单和明确的“不迁移清单”。
- PR #652 中独立的 Terminal Bridge 增量不得随目录删除而误删。

### A-FR-02 文档和开发入口

- 新增 `hci_sim/README.md`，覆盖本地运行、测试、镜像构建、Fixture、Lease、Bridge smoke、错误语义和安全限制。
- 全仓库不得再出现把 `hci-sim/` 当源码目录的活动构建或操作指引。
- 命名规范必须解释下划线源码目录与连字符服务名的边界。

### A-FR-03 CI 基础门禁

PR 至少执行：

```text
go test ./...
go vet ./...
go build ./cmd/hci-sim ./cmd/hci-sim-smoke
Fixture/Helm manifest 漂移检查
helm lint/template
```

`go test -race ./...` 应在关键 PR 或定时流水线执行，不得长期只依赖 Docker build 证明正确性。

### A-FR-04 反退化门禁

自动测试必须阻止重新引入：

- `--accept-any-password`；
- 空 Lease Secret 放行；
- 未认证的 scenario env；
- unknown Fixture 返回 exit 0；
- sim miss fallback 到真实 HCI；
- 任意 shell 执行；
- 第二套 hci-sim Go module。

### A-FR-05 当前事实基线

阶段完成时必须固化但不得夸大的事实：

- KBD 27123 仅有历史 revision 1 静态 Golden Fixture；
- 当前集群是否在线必须通过实时检查决定；
- Fixture Compiler、Registry、Scenario API、Scheduler、通用 Runner 尚未实现；
- 历史 E2E 不代表当前 active KBD revision 已验证。

## 4. 非功能需求

| 编号 | 要求 |
|---|---|
| A-NFR-01 | 删除重复目录不得改变真实 HCI `ssh` 默认路径。 |
| A-NFR-02 | 所有测试必须可在干净 checkout 重复执行。 |
| A-NFR-03 | CI 不得读取或打印 Lease、SSH 私钥或真实 HCI 凭据。 |
| A-NFR-04 | 文档、CI、Dockerfile、Helm 与构建脚本对源码入口必须一致。 |
| A-NFR-05 | 工作区中的用户未提交改动必须被保留。 |

## 5. 范围外

- 不实现 Fixture Compiler。
- 不增加数据库控制面表。
- 不实现多 Bundle 动态加载。
- 不宣称支持任意 KBD ID。
- 不执行 100+ 容量测试。
- 不借目录收敛重写 Terminal Bridge 或 Agent 主流程。

## 6. 依赖与后继

- 前置：现有 `hci_sim`、Helm Chart、Terminal Bridge sim-ssh 增量可编译。
- 后继：阶段 B 只能在 A 验收通过后开始。
- 阶段 A 的完成不代表 hci-sim Runtime 已达到多租户生产质量。

## 7. 验收标准

- [ ] 仓库只剩一个 hci-sim 源码目录 `hci_sim/`。
- [ ] 所有正式构建、测试和文档入口指向 `hci_sim/`。
- [ ] `hci_sim/README.md` 可以让新成员完成本地测试和 smoke。
- [ ] 单测、vet、build、race、Helm lint/template 全部通过。
- [ ] 反退化用例覆盖任意密码、空 Lease、unknown、fallback 和重复 module。
- [ ] 当前事实文档明确“历史 Golden Slice，不是通用平台”。
- [ ] 阶段 A 验证报告具备命令、版本、输出摘要和 Git SHA 证据。
