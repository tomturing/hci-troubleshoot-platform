## 执行顺序与提交策略

1. `A-01/A-02` 只读取证，不修改源码。
2. README 迁移独立提交，确保删除前可审阅。
3. 目录删除独立提交，不能夹带 Runtime 重构。
4. 引用与 CI 门禁可分提交，但合并前必须全部绿色。
5. 文档只有在实际证据完成后才把现行事实由“两目录存在”改为“已收敛”。

## 实现检查

- [x] `rg --files` 只剩一个 hci-sim Go module 源码入口。
- [x] 旧实现的 accept-any、可选 Lease、score router、默认 Fixture 回退、无界 goroutine、长 sleep 和 raw command log 未迁移。
- [x] `hci_sim/README.md` 明确源码名、部署名、开发/测试、安全边界和 A–E 路线。
- [ ] CI 使用 module 的 Go 版本，缓存键包含 `go.sum`，失败不会被无条件重试吞掉。
- [ ] race 策略对 `hci_sim/**`、Bridge、Manifest 和 Chart 变更生效。
- [ ] 静态 Manifest 重复来源有唯一生成/校验策略，不允许静默漂移。
- [ ] 正式构建、Helm/K3s 和开发命令仍产出/部署 `hci-sim` 服务。

## 测试任务

- [ ] 对反退化脚本注入一个临时反例，证明门禁会失败，再移除反例。

- [ ] 验证真实 SSH 路径不因目录清理被标为 simulation。
- [ ] 验证 sim smoke 的 Lease、Manifest digest、fixture hit/miss 和 exit-status。
- [ ] 扫描仓库、CI 和发布日志，确认无旧源码目录消费者。

## 文档与部署任务

- [ ] 更新 `docs/README.md` 当前状态，不复用历史集群状态。
- [ ] 更新需求、架构、接口、部署、任务和测试现行全量文档。
- [ ] 实施完成后更新 `AGENTS.md` 的唯一源码事实和标准命令。
- [ ] 如未实际部署，不得把 namespace 或当前服务写为在线。

## 回滚

- 目录删除以独立 commit 回滚；不得回滚同一历史 PR 中 Terminal Bridge 的独立能力。
- 若发现外部消费者，先恢复旧目录到删除前 SHA、冻结后续阶段并登记 consumer；迁移 consumer 后重新删除。
- 临时 shim 必须无第二套源码、有 owner 和到期日；不能变成长期双实现。

## 阻断条件

- 发现未登记的生产/发布消费者且无法在窗口内迁移；
- 删除会丢失无法在 `hci_sim` 安全重写的必要业务契约；
- Go/race/Helm/Bridge/真实 SSH 任一基线回归；
- 无法证明旧不安全能力未被迁移；
- 验证证据缺少 Git SHA、工具版本或可复现命令。
