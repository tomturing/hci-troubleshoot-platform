## 核心 KBD 工作包

- [ ] 记录 Tool、Matcher、变量链、节点/容器、输出规模和故障域覆盖。
- [ ] 每个 KBD 绑定精确 revision、approved Artifact、Bundle digest 和 owner。
- [ ] 覆盖 positive/negative/near-miss/unknown/timeout/permission 等适用 variants。
- [ ] 不可编译项保留 capability gap、业务影响、计划和 SLA，不从样本中移除。
- [ ] 每个认证包包含 differential、mutation、20-repeat 和已知限制。

## 差分与 Mutation 任务

- [x] 差分结构要求 real/sim 为独立 Observation；真实 calibration group/Runs 待环境接入。
- [ ] 比较 command、stdout/stderr/exit、变量、Matcher、Signal、Conclusion 和证据。
- [ ] 允许差异版本化；禁止差异无 waiver 时自动 stale/block。
- [x] Mutation 检出率、critical miss 与等价 mutation 排除语义已实现；完整 corpus 待接入。
- [ ] 每个 mutant 有预期检测层；等价 mutant 排除有专家理由。
- [ ] 关键结论/安全 mutant 检出率为 100%；总体阈值经试点批准。

## 稳定性与容量任务

- [ ] 保存 20 次首次 Attempt，自动重试不改写 first-attempt 指标。
- [ ] 统计 pass/flaky/inconclusive/infra error 和 duration 分位数。
- [ ] 逐级执行 1/10/50/100/200；前级失败不进入后级。
- [ ] 固定数据集、seed、到达模型、fault 比例、cache 状态和持续时间。
- [ ] 采集 queue/CPU/RSS/GC/goroutine/SSH/output/cache/Redis/DB/cleanup。
- [x] 容量证据把跨 Scenario 污染设为零容忍停止条件；真实 canary/指标采集待接入。
- [ ] 分别记录 100 SSH Scenario、100 Agent 和 100 browser 声明，不能互相替代。

## 持续运营任务

- [ ] 依赖图能计算 KBD/Tool/Policy/Compiler/Runtime/Bridge/Agent 影响集。
- [ ] PR 运行小型 affected suite，nightly 运行核心 suite，周期任务做完整校准/容量。
- [ ] dashboard 显示 validated/stale/gap/flaky/drift/mutation/capacity/owner。
- [ ] 告警覆盖 fixture miss、overload、cleanup leak、串线、secret 和真实访问。
- [ ] waiver 有范围、owner、风险、补偿、批准人和自动到期。
- [ ] runbook 包含停止测试、撤销 Lease/Bundle、隔离证据和恢复条件。

## 失败与停止条件

以下任一情况立即停止相关测试、保全证据并启动 P0 流程：跨 Run/租户串线、真实凭据/客户数据泄漏、sim 非预期访问真实 HCI、签名/完整性绕过。普通性能未达标、flaky 或 capability gap 不能伪装通过，进入 blocked 并分配 owner。

## Definition of Done

- [ ] 10～20 个核心 KBD 的精确 revision 有完整认证包，gap 透明可追踪。
- [ ] differential、关键 mutation、20-repeat 达到批准阈值。
- [ ] 1/10/50/100/200 报告可复现，100 Scenario 零串线，200 受控降级。
- [ ] 故障和安全演练通过，未发生 secret 泄漏或 sim→real fallback。
- [ ] PR/nightly/周期流水线、SLO、告警、dashboard、runbook 和 owner 运行有效。
- [ ] 产品评审基于不可变 Evidence Manifest 签署声明范围；未签署前不得宣称产品级完成。
