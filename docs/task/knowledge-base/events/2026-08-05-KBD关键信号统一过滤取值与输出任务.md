## 兼容与回归约束

1. 历史 `rows` 缺少 exclude_mode 时按 `any`；缺少 scope 时按 `same_record`。
2. 历史 Matcher expected/not 继续运行，新编辑不再依赖通用取反。
3. 历史 qfk_service `resource_keyword/command` 只读归一，新编辑保存 `service/action`。
4. 显式 timeout 不覆盖；只有缺省与新建值改为 60。
5. `deploy/helm/hci-platform-obs/values.yaml` 属于原工作区用户改动，不得出现在本分支。
