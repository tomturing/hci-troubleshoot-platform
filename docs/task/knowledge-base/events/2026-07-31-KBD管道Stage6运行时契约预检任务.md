## 操作验收

```bash
cd /aihci/hci-troubleshoot-platform
uv run python -m data-pipeline.kbd.run --help
uv run python -m data-pipeline.kbd.run audit-log-signals --file /path/to/signals.json
uv run python -m data-pipeline.kbd.run pipeline --ids 40061 --override --override-status all --force-fetch
```

最后一条在正常环境中仍会执行真实数据生产，不能作为单元测试替代；首次验证应先使用
`audit-log-signals --file` 的只读输入，再选择单条 draft KBD 运行完整链路。
