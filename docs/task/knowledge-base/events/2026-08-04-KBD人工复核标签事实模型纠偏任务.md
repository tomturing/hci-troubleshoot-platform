# KBD 人工复核标签事实模型纠偏任务

## 关联文档

- [人工复核标签事实模型纠偏方案](../../../solution/knowledge-base/events/2026-08-04-KBD人工复核标签事实模型纠偏方案.md)

## 最终规则

```text
不需要人工复核 → 不显示标签
需要复核、专家尚未保存 → 需人工复核
需要复核、当前内容已被专家保存 → 已人工复核
```

## 实施约束

1. 现有复核要求仍由 `provenance.needs_review || review.require_human_confirm` 判断。
2. 普通 Signal 不显示“已人工复核”。
3. Expert/Published 本身不能让普通 Signal出现绿色标签。
4. 专家保存事实使用现有 Revision，不增加可编辑的审核布尔值。
5. API 字段是只读派生数据，不写回 `signals_json`。
6. Candidate 三态和机器执行安全门禁不参与标签判断。
7. 不修改或提交用户已有的 `deploy/helm/hci-platform-obs/values.yaml` 改动。

| 否 | 否 | 无标签 |
| 否 | 是 | 无标签 |
| 是 | 否 | 需人工复核 |
| 是 | 是 | 已人工复核 |

## 完成定义

- 三态规则在后端只有一个派生实现；
- 前端不再从 unrelated 状态猜测审核事实；
- 专家保存前后标签按矩阵转换；
- 不增加数据库持久化状态；
- 自动测试、构建、文档治理和 CI 全绿；
- 通过 PR 合并。
