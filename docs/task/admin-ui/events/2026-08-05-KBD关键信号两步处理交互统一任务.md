## 实施目标

在不改变后端 Signal 契约的前提下，将 QFK 匹配模式和产出变量统一呈现为：

```text
处理单元 → 第一步：取值 → 第二步：判断/产出
```

## 对抗性检查

- 不把第一步关键字自动复制到第二步；
- 不把第二步判定关键字反推为第一步行筛选；
- 不让多个变量共享同一个 Extract 对象；
- 不让嵌入 Matcher 再渲染一份 ValueExtract；
- 不使用“变量处理单元”“第二步：产出变量”“声明式取值”旧术语；
- 不修改数据库、Signal Schema 或历史 Revision。
