# acli 自动检测与安装更新任务

## 关联方案

[2026-09-20-acli自动检测与安装更新方案.md](../../../solution/custom-ui/events/2026-09-20-acli自动检测与安装更新方案.md)

## 背景

在合入 PR #1056 后环境验证发现 HCI 未安装 `acli` 工具，导致工单创建时环境数据采集失败。需在 SSH 连接后自动化检测 acli 并在缺失或旧版本时自动下载安装升级。

---

## 任务清单与执行记录

### T1：Terminal Bridge 后端协议扩展与自动同步实现
- **文件变更**：`terminal_bridge/main.go`、`terminal_bridge/main_test.go`
- **内容**：
  - 扩展 WebSocket 消息模型：`acli_sync`、`acli_sync_progress`、`acli_sync_result`。
  - 增加快速执行命令函数 `runQuickCommand`，支持执行命令并获取 stdout/stderr 及退出状态。
  - 增加系统架构与版本提取：执行 `uname -m` 与 `acli --version`，结构化解析版本号与 build 日期。
  - 增加远端源秒级元数据探测：通过 HTTP GET `Range: bytes=0-0` 请求深信服下载接口，从 `Content-Disposition` 提取最新版本时间戳。
  - 增加磁盘空间安全门禁：通过 `df -P -m /sf/data/local` 校验可用空间。
  - 增加流式边下边传与静默安装：HTTP 下载直连 SFTP 上传到 `/sf/data/local/`，执行 `--install --force` 静默多节点部署，并在完成后清理安装包。
- **状态**：✅ 已完成，通过自动化单测。

### T2：前端 API 与 Terminal WebSocket 协议类型定义
- **文件变更**：`frontend/customer/src/api/terminal.ts`
- **内容**：
  - 增加 `acli_sync_progress` 与 `acli_sync_result` 事件类型。
  - 增加 `buildAcliSyncMessage` 消息构造辅助函数及相关选项类型。
- **状态**：✅ 已完成。

### T3：前端 acliManager 模块与状态管理

  - 单元测试覆盖：已是最新跳过、版本更新、磁盘空间不足报错、超时防护。
- **状态**：✅ 已完成，4 项单测全部通过。
