## 实施步骤

1. `terminal_bridge/log_collect.go`：`parseLogCollectModuleCatalog` 不再把 acli help 的说明文字（"约4min"、""不收与上述n个场景"）当选项名渲染，`label` 一律取自平台内置短名 `logCollectModuleLabels`；并按白名单全集 `logCollectModuleCatalogOrder` 补齐，保证 `core` 等合法枚举始终可选（实机 acli 1.0.1 的 help 未列出 core，原会被静默丢掉）。仍以"解析到至少一个合法枚举"判 help 可用，乱码时回退内置目录。
2. `terminal_bridge/log_collect.go`：`catalog_note` 节点清单失败时不再拼接 stderr 原始输出（acli 的 JSON 运行日志 / Go 栈 / cgroup 路径），改为"节点清单获取失败，可手动填写 IP（详细错误见桥日志）"，原始输出只留桥日志。
3. `frontend/customer/src/components/LogCollectPanel.vue`：探测卡「交付路径」改名为「建议路径」，与表单中的用户决策（交付路径）区分；无任务时 label 仍带「建议」二字，避免被读成"已经定了 P1"。
