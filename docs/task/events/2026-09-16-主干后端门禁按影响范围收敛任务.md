## 关键实现约定

- **diff 起点**：复用 `resolve_release_baseline.py` 输出的 `base_sha`（最近一次成功
  镜像发布基线），不使用 `github.event.before`，避免被取代的中间 push 变更漏回归。
- **失败关闭**：`git diff` 失败时清空清单并输出告警，脚本对空清单返回
  `required=true`；job 输出的缺省值同样是 `'true'`。
- **白名单准入**：每条路径必须逐 job 核对"没有任何步骤读取"，不接受"看起来无关"的
  推断；`deploy/` 因 `config-contract-check` 与 `docker-compose` 输入明确排除。
- **手动触发一致性**：`main-test-plan` 仅在 `push && refs/heads/main` 执行，因此
  `workflow_dispatch` 下输出回落缺省 `'true'`，手动发布天然是完整门禁。
