## 反模式检查（不得出现）

| 反模式 | 说明 |
|---|---|
| 硬编码 198 类词表到代码/prompt | 基线动态演进，写死即腐化 |
| 对 KBD 原始输入做硬校验/拒抽 | 违背输入容忍 |
| 类型↔关键字强冲突时硬拒保存/抽取 | 阻断诊断路径，软告警即可 |
| 全等匹配判断 keyword 命中基线 | 不容忍错别字/同义词，误报 |

## 验收落点（对应设计文档 §验收标准）

1. 输入容忍：KBD 错别字/同义词正常抽取；前端编辑错别字 keyword 不被拦截。
2. 实时基线：4.2 实现后，Admin 增删/改名分类后校验行为随之变化（非写死）。
3. 类型↔性质软告警：前端 `qkv_alert` 填"…失败"类、`qkv_task/dialog` 填"…告警"类时出现高亮告警，但不阻止保存。
4. 不阻断：任何一层不匹配只产生 `warnings`/提示，不拒绝抽取或保存。
