# 交付期间 SSH 会话掉线自动重连（任务）

## 关联文档

[2026-10-28-交付期间SSH会话掉线自动重连方案.md](../../solution/events/2026-10-28-交付期间SSH会话掉线自动重连方案.md)

## 实施步骤

1. `terminal_bridge/main.go`：`on_output_start` 三处 `sendMsg(ws, ...)`（`exec_result`、`ssh_output`、`ssh_disconnected`）加 `if ws != nil` 保护。
2. `terminal_bridge/main.go`：新增 `Bridge.reconnectDeliveryNode(caseID, nodeIP, connID)`，复用 `lastAuth` 后台重建会话，EOF 按规则销毁/摘键，记 `delivery.session_reconnected`。
3. `terminal_bridge/delivery_runner.go`：`sessionFor` 在 `resolveLogCollectSession` 返回 nil 且 `deliveryPhaseNeedsNode(phase)` 时调用 `reconnectDeliveryNode`，两分支都落空才返回 nil。
4. 新增 `terminal_bridge/delivery_reconnect_test.go`：nil-ws 不 panic、已有会话复用、无认证返回 nil。

## 验证

- `cd terminal_bridge && go test ./...` 全绿；新增用例覆盖改动点。
- 现场：节点 SSH 会话掉线后交付自动恢复并完成（库内 `delivery_status=delivered`），无需人工重连；无认证时仍 `needs_reauth`。
