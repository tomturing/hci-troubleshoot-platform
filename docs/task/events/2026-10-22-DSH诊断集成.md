## 任务清单

### T1: 构建 DSH 容器镜像

- **描述**：编写 `docker/dsh/Dockerfile` 与 `docker/dsh/docker-entrypoint.sh`。基础镜像 `node:22-alpine`，全局安装 `@deepseek-ai/dsh@0.2.1-rc.2`。entrypoint 后台启动 `dsh --profile web --port 3080 --public-url <公共URL> --trusted-host <域名> --no-open`，轮询 stdout 中的 `dsh web: ` 行抓取 token，原子写入 `/run/dsh/token`，前台等待进程退出。
- **文件变更**
  - 新增 `docker/dsh/Dockerfile`
  - 新增 `docker/dsh/docker-entrypoint.sh`
  - 新增 `docker/dsh/nginx/`、`docker/dsh/nginx/dsh-proxy.conf.template`
- **验收标准**：`docker build` 成功；容器启动后 `/run/dsh/token` 内有与 stdout 打印一致的 token 值。
- **依赖**：无
- **预计耗时**：2 小时
- **状态**：待开始

### T2: 编写 Helm Chart hci-platform-dsh

- **描述**：新建 `deploy/helm/hci-platform-dsh/`，含 namespace、Deployment（dsh + nginx sidecar 双容器，共享 emptyDir 交换 token）、Service（8080 指向 nginx）、ConfigMap（nginx 配置）、Ingress（`/dsh` 前缀，priority 2500）、NetworkPolicy（默认关闭）、PVC（DSH 家目录）。
- **文件变更**
  - 新增 `deploy/helm/hci-platform-dsh/Chart.yaml`
  - 新增 `deploy/helm/hci-platform-dsh/values.yaml`
  - 新增 `deploy/helm/hci-platform-dsh/templates/_helpers.tpl`
  - 新增 `deploy/helm/hci-platform-dsh/templates/{namespace,deployment,service,configmap,ingress,networkpolicy,pvc}.yaml`
  - 新增 `.helmignore`
- **验收标准**：`helm lint` 通过；`helm template` 渲染出预期资源；Ingress 路径为 `/dsh` 且 priority 2500；hostPath 只读挂载 `/sf/log`。
- **依赖**：T1
- **预计耗时**：3 小时
- **状态**：待开始

### T3: api-gateway 新增 /api/dsh/launch

- **描述**：新增 `backend/api-gateway/app/routes/dsh.py`，提供 `GET /api/dsh/launch`，以 `Depends(require_admin)` 强制管理员鉴权，经 Service `dsh.hci-dsh.svc.cluster.local:8080/__internal/token` 拉取 token，返回 `{ "url": "/dsh/?token=<t>" }`。上游不可用时返回 503。在 `main.py` 注册路由。
- **文件变更**
  - 新增 `backend/api-gateway/app/routes/dsh.py`
  - 修改 `backend/api-gateway/app/main.py`
  - 新增 `backend/api-gateway/tests/unit/test_dsh_route.py`
- **验收标准**：未携带有效 JWT 返回 401/403；鉴权通过且上游可用时返回含 token 的 URL；上游不可用时 503；单元测试通过。
- **依赖**：无
- **预计耗时**：2 小时
- **状态**：待开始
