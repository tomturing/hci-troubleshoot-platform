# 任务：日志收集输出语言适配（不再只认中文文案）

## 背景

2026-11-06 工单 `Q2026110486009`（节点 `10.12.10.11`）现场：5 个节点采集全部成功、
11 分 13 秒生成 10,776,741,492 字节的包，但面板恒显示 `0% (0/0)`，平台任务停在
`collecting`、`progress=0`、`delivery_status=none`，既不降级 P2 也没有补交付入口。

根因不是采集失败，而是**解析器只认中文文案**：该机器上的 `acli`（1.0.0，build
`2026-05-20 17:22:16`，与另一台输出中文的机器完全同版本）输出英文：

```
Status: Collect task has been completed!
Overall progress: 100% - 5/5(Collected/Total collected)
10.12.10.22  Collection successful   100%
Send address: http://acli.sangfor.com.cn:5888
Status: Failed
```

`terminal_bridge/log_collect.go` 的解析只比对 `总进度：`/`状态：`/`发送地址：`/
`压缩包路径`/`总耗时：` 与 `收集完成|收集中|收集失败`，于是全部落空：

- `parse_ok=false`，`status_text`、`upload_state` 为空，`hosts_count=0`；
- 平台读不到"已完成"，也读不到"上传失败（5888 401）"，因此不降级、不进补交付队列；
- 同一台机器的场景目录也失效（`catalog_source=platform_default`、
  `catalog_note=acli 帮助解析失败`），与上面是同一个语言变量。

即 **`catalog_source=platform_default` + `parse_ok=false` 就是"这台机器 acli 讲英文"的指纹**。

## 任务清单

### T1: 进度解析改为语言无关
- 描述：把中文前缀硬匹配换成「标签 + 冒号 + 值」的结构匹配；进度行按
  `标签 + 百分比 + 分数`、节点行按 `行首 IP + 状态列 + 行尾百分比/横线` 的形态识别。
- 文件变更：`terminal_bridge/log_collect.go`
- 验收：英文样本解析出 `status/percent/done/total/archive_path/total_time/upload_url/upload_state`
  与 5 条节点明细；中文既有用例零回归。
- 状态：已完成

### T2: 上传地址只切第一个冒号
- 描述：`http://acli.sangfor.com.cn:5888` 自带端口冒号，取最后一个冒号会把地址切成 `5888`。
- 文件变更：`terminal_bridge/log_collect.go`
- 验收：`upload_url` 完整保留端口；单测 `TestParseLogCollectProgressEnglish` 覆盖。
- 状态：已完成

### T3: 节点态归一化中英双覆盖，且 `none` 必须在 `running` 之前
- 描述：英文无任务文案 `Collect task does not exist!` 含 `collect`，若先判 running
  会被归成"进行中"，平台会一直等下去。
- 文件变更：`terminal_bridge/log_collect.go`、`frontend/customer/src/services/logCollectSync.ts`
- 验收：`classifyLogCollectNodeState` 与前端 `fallbackNodeState` 对中英样本结论一致。
- 状态：已完成

### T4: 场景目录解析兼容英文 help
- 描述：`acli log_collect create --help` 的英文枚举是 `name (Label)`（半角括号、带空格），
  中文是 `name（标签）`。括号与空白都兼容；找不到标题（`枚举值`/`Enum values`）时全量扫描兜底，
  且**只统计白名单枚举**，避免正文里的 `file (Please ...)` 被当成目录而谎称"来自集群"。
- 文件变更：`terminal_bridge/log_collect.go`、`terminal_bridge/log_collect_test.go`
- 验收：`TestParseLogCollectModuleCatalogEnglishFallback` 通过；只有正文括号时返回空。
- 状态：已完成
