## 根因与处置结论

`sfvt_vtpdaemon.log` 不支持 `delta` 是本次具体失败原因；`minimum_samples=2` 配合 `cardinality=last` 是第二个潜在运行时错误。旧日志只记录 HTTP 状态，没有错误语义和跨服务 ID，导致专家无法行动。代码现以稳定错误契约、结构化日志、HTTP 指标和前端定位闭环解决。

## 回滚与风险

错误响应保留旧 `detail` 形态；新增字段和响应头均向后兼容。日志只追加字段，不改变采集格式；若指标注册冲突，需检查共享 Prometheus registry 后回滚新增 Counter。
