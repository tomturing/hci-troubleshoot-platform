# hci_sim 独立数据库隔离任务

对应方案：[hci_sim 独立数据库隔离方案](../../solution/events/2026-08-10-hci_sim独立数据库隔离方案.md)

## 1. 变更分层

数据库变更必须拆成至少四个可回滚 PR/发布单元：

```text
PR-A inventory + boundary + migration framework
PR-B expand/copy/verify + hci-sim connection switch
PR-C observe/freeze + application cleanup guards
PR-D contract/drop old hci-sim tables（观察窗口后）
```

不得把创建新库、应用切换和 DROP 旧表放进一个 PR。

## 2. P0：Inventory 和边界确认

- [ ] 导出 `hci_troubleshoot` 全部表、列、约束、索引、序列、触发器、view、function、RLS、权限。
- [ ] 对 `agent_test_*`、fixture、artifact、run、runtime、audit 和 bridge execution 表生成行数/增长率报告。
- [ ] 使用 `rg`/AST/ORM 扫描所有 SQL、模型、repository、报表、备份和迁移引用。
- [ ] 记录 `public.<table>`、search_path 和跨服务原始 SQL 硬编码。
- [ ] 对 `bridge_execution_artifacts/logs` 标注真实 HCI 使用方与 sim-ssh 使用方。
- [ ] 输出 ownership matrix：创建者、读取者、生命周期、保留期限、敏感等级。
- [ ] DBA/平台/Agent/审计负责人签字确认迁移清单。

## 3. P0：新数据库与角色

- [ ] 创建 `hci_sim` database，禁止应用角色作为 owner。
- [ ] 创建 owner/migrator/runtime 角色并撤销 PUBLIC CREATE/CONNECT（按实际管理策略配置）。
- [ ] 创建 control_plane、fixture、artifact、execution、audit schema。
- [x] 创建独立 K8s migrator/runtime Secret，迁移 Pod 通过 `secretKeyRef` 注入；平台管理员密码也改为 `hci-secrets.POSTGRES_PASSWORD` 引用，不再进入 Pod spec 明文 `env.value`。
- [ ] 增加 hci-sim 专用 ConfigMap/env contract；缺失 `HCI_SIM_DATABASE_URL` 时 fail-closed。
- [ ] 创建数据库连接池、超时、重试和健康检查配置；禁止读取平台 `DATABASE_URL` fallback。

## 4. P0：独立 migration framework

- [x] 新建 `database/hci-sim-migrations/`，按领域 schema 管理 hci_sim DDL；独立 history/Atlas 接入在后续 PR 补齐。
- [ ] 从主库 migration 中标注/迁出 hci-sim DDL，确保主库新部署不再创建新表（必须在 copy/switch 后执行，避免丢失存量）。
- [x] 创建独立 migration Job/Hook，使用 migrator/runtime Secret 和明确 hook-delete-policy。
- [x] 为空库编写独立 CI migration、schema 和 DDL 负向门禁。
- [ ] 为存量库、重复执行、版本跳过和 checksum 变化补齐 Atlas 测试。
- [x] 增加 CI path gate：hci-sim migration 独立触发，不复用主库 Schema Job。

## 5. P1：Expand 与数据复制

- [ ] 在非生产复制数据上执行 schema 创建和结构复制。
- [ ] 按 FK 依赖顺序复制表、索引、约束、序列、评论和权限。
- [ ] 对禁止迁移字段执行过滤（Lease 明文、原始 Artifact、外部 URL 等）。
- [ ] 生成行数、PK、摘要、FK、索引和 sequence 校验报告。
- [ ] 处理大表分批复制、锁超时、重试和断点续传；每批幂等。
- [ ] 记录源库/目标库 snapshot 时间和 final delta 窗口。

## 6. P1：应用切换

- [ ] hci-sim compiler/control-plane/runtime 读取独立连接配置。
- [ ] agent-service/Bridge execution 只通过明确控制面 API 访问 hci_sim，不直接复用主库连接。
- [ ] TestRun/Bundle/Artifact 新建写入目标库；主库业务回归不受影响。
- [ ] 通过 feature flag/Secret 进行单环境切换，保留旧连接回滚。
- [ ] 禁止在旧库和新库之间实施无 outbox 的 best-effort 双写。
- [ ] 切换后对旧表设置只读/触发告警，观察至少一个完整 TestRun 生命周期。

## 7. P1：权限、安全和恢复

- [ ] runtime 角色不能 DDL、不能访问 `hci_troubleshoot`。
- [ ] 主平台角色不能默认访问 `hci_sim`。
- [ ] migrator 角色仅在 migration Job 中短时使用，Job 完成后撤销/轮换。
- [ ] 备份 hci_sim 并恢复到临时实例；执行 schema、行数和业务查询校验。
- [ ] 验证 Secret 轮换和 Pod 滚动重连。
- [ ] 配置 hci_sim 独立容量、连接池、错误率、备份和 stale outbox 告警。

## 8. P2：旧表冻结与清理

- [ ] 观察窗口内确认旧表无新写入，查询 source code 无旧连接引用。
- [ ] 生成 contract/drop 评审清单和恢复点。
- [ ] 先重命名/只读保留，再在独立 PR 删除旧表、索引、序列和触发器。
- [ ] 删除后运行主库 schema drift、备份恢复和平台业务回归。

## 9. 阻断条件

以下任意一项未满足，禁止切换或删除：

- 未完成 inventory/ownership；
- 未验证备份恢复；
- 发现硬编码主库连接或 public 表引用；
- 目标行数/PK/FK/sequence 校验不一致；
- runtime 可通过错误账号访问主库；
- bridge execution 表 ownership 未明确；
- 没有一键回滚 Secret/config；
- 主库旧表仍有写入。

## 10. 完成定义

以验证文档中的权限、迁移一致性、切换、回滚、观察和删除门禁全部通过为准；“hci_sim database exists”不等于任务完成。

当前状态：PR-A（独立数据库与迁移框架）进行中；copy/verify/switch/contract 尚未完成，不能将本 PR 作为数据库隔离最终验收。
