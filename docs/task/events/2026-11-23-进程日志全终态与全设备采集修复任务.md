# 2026-11-23 进程日志全终态与全设备采集修复任务

## 关联方案

[2026-11-23 进程日志全终态与全设备采集修复方案](../../solution/events/2026-11-23-进程日志全终态与全设备采集修复方案.md)

## 任务清单

### T1：exec_id 鲁棒化（前端注入 + bridge 回退）

- **描述**：在 `sendAndWait` 统一发送层注入当前 `exec_id`（来源 create 返回的 `task_id` /
  接管的 `resumedTaskId`），使 progress/cancel/stat/transfer 均携带；bridge 侧
  `EvidenceFor` 取不到时按 `case_id` 在内存中反查唯一有效配置并落回退事件。
- **文件变更**：
  - `frontend/customer/src/components/LogCollectPanel.vue`
  - `terminal_bridge/internal/logcollect/log_collect_evidence.go`
  - 对应单测
- **验收标准**：新任务 `log_collect.progress` 事件 `task_id` 非空率 100%；
  `EvidenceFor("")` 回退单测通过且不误采多任务并存的 case。
- **依赖**：无
- **预计耗时**：2 小时
- **状态**：待开始

### T2：终态钩子与三轮采集（含 empty 落库、去重键改造）

- **描述**：把 `collectNodeLogs` 从 `:519` 成功门移到 `HandleLogCollect` 的 `defer`
  终态钩子；`init` / `terminal` / `terminal_failed` 三轮；空目录落 `empty` 行；
  `evidenceOnce` key 增加 `phase`；单任务预算按轮独立。
- **文件变更**：
  - `terminal_bridge/internal/logcollect/log_collect.go`
  - `terminal_bridge/internal/logcollect/log_collect_node_logs.go`
  - `backend/case-service/app/routes/log_collect_evidence.py`
  - `database/desired_schema.sql` + `database/data-migrations/069_*.sql`
- **验收标准**：成功/SPC 失败/用户取消/acli 安装失败四类任务均有日志行或 `empty`；
  同任务三轮共存且唯一键冲突不再吞掉不同轮记录。
- **依赖**：T1（exec_id 注入是终态钩子命中证据配置的前提）
- **预计耗时**：4 小时
- **状态**：待开始

### T3：全设备 SSH 扇出与预算隔离

- **描述**：主机清单取 `ExpectedHosts` → `ips=all` 时 `cluster.NodeList`；
  复用 `cluster.RunOnHostStreams` 逐台只读采集，`payload.Host` 填真实来源 IP；
  单机失败隔离并落事件；预算按主机均分、未用完汇总；`local` 由
  `cluster.LocalAddresses` 判定避免 ssh 自己。
- **文件变更**：
  - `terminal_bridge/internal/logcollect/log_collect_node_logs.go`
  - `terminal_bridge/internal/logcollect/log_collect_evidence.go`
  - `terminal_bridge/internal/shared/cluster/cluster.go`（若需复用扩展）
  - fanout 单测
- **验收标准**：多主机任务（≥2 台）日志 `host` 覆盖全部可达目标；
  单机不可达时其它主机仍完成；`BatchMode=yes`/`ConnectTimeout=5` 生效。
- **依赖**：T2
- **预计耗时**：4 小时
- **状态**：待开始

### T4：后端 phase 字段与管理端展示

- **描述**：`/process-logs` 端点新增可选 `phase`（缺省 `terminal`），按轮预算；
  管理端清单接口与前端表格增加 `phase` 展示，默认只显示终态轮、无终态轮回退 init 轮。
- **文件变更**：
  - `backend/case-service/app/routes/log_collect_evidence.py`
  - `backend/case-service/app/routes/log_collect_admin_tasks.py`
  - `frontend/admin/src/views/components/LogUploadPanel.vue`
  - `frontend/admin/src/api/logCollectAdminTasks.ts`
- **验收标准**：旧桥无 phase 上报仍兼容；管理端能区分「初始轮/终态轮」且不重复堆叠。
- **依赖**：T2
- **预计耗时**：3 小时
- **状态**：待开始
