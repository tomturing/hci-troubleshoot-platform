# QFK 完整输出 AI 提取任务

> 对应方案：[QFK 完整输出 AI 提取方案](../../../solution/agent/events/2026-08-05-QFK完整输出AI提取方案.md)

## 背景

为 QFK 的完整日志证据增加受控 AI 定位能力，且必须保证 Matcher 和变量产出没有两套语义。

## 任务目标

1. 扩展 `ValueExtract` Schema 和管理台输入；
2. 在确定性选行/命中之后执行 AI 提取并逐字溯源；
3. 将同一结果用于 Matcher evidence 和 produces 变量池；
4. 为失败关闭、候选上限与原子写入补回归。

## 执行过程

- 新增 `ai_extractor.py`，封装候选构造、JSON 协议、类型转换、行号和值回查；
- `qfk_exec()` 只在正向确定性命中后调用它；
- `KBDDiagnostic` 在写变量池之前汇总所有 AI 结果；
- 生成 Schema 产物并更新 Admin `ValueExtractEditor`；
- 补充 AI 提取、变量池原子性、Schema 校验测试。

## 验收结果

- [x] 关键字 AND 的 AI 候选限制为同一行同时含全部关键字；
- [x] 不存在于引用行的 IP 被稳定码 `QFK_AI_EXTRACT_UNGROUNDED` 拒绝；
- [x] AI produces 成功写入变量池，失败时不产生部分变量；
- [x] `check_signal_schemas.py`、Agent/KBD 定向测试与 Admin 构建通过。
