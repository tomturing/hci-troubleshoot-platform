## 专家复核操作已经具备的入口

1. 在 Admin 的 KBD 管理页筛选待审核 Proposal；
2. 检查分类、截图 Evidence 与关键信号；必要时新增、编辑、排序、复制或删除 Signal；
3. 删除 Signal 时选择结构化原因，修改时填写适当的审核说明；
4. 普通保存形成专家工作稿，确认后执行“审核通过并发布”或“发布维护版”；
5. 发布后由 Agent 实际使用积累 compile、Signal outcome、失败模式与 replay manifest。

实际案例的“审核通过/拒绝”仍需专家判断。本任务不会以脚本、LLM 或测试 fixture 伪造任何 Expert Gold 记录。
