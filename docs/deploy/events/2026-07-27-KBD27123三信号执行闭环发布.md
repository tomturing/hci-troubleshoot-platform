无数据库结构变更。KBD 27123 已通过管理 API 更新并发布为动态资源 revision 17。

## 发布顺序

1. 合并 PR，等待 CI 构建上述服务镜像。
2. 确认 ArgoCD/部署系统同步到同一 commit tag。
3. 确认 Deployment 不存在源码 ConfigMap `subPath` 热补丁。
4. 确认 customer-ui 下载件 checksum 已更新。
5. 旧 terminal_bridge 可由新 UI 兼容筛选完成回归；正式交付仍应下载并重启新 bridge，使 39 MB 原始输出不离开客户机本地进程。

## 发布后检查

```bash
kubectl get deploy -n hci-dev agent-service conversation-service kb-service customer-ui \
  -o custom-columns=NAME:.metadata.name,IMAGE:.spec.template.spec.containers[0].image

kubectl get deploy -n hci-dev agent-service conversation-service kb-service \
  -o json | jq '[.items[].spec.template.spec.containers[].volumeMounts // [] | .[] | select(.mountPath | startswith("/app/"))]'
```

下载 bridge 后应检查版本/构建时间，并用新工单验证 `exec.done` 中：

- `stdout_raw_len` 仍反映原始输出规模；
- `stdout_filtered=true`；
- `stdout_len` 仅为命中行大小；
- `output_overflow=false`。
