# KBD 专家信号修复与删除可用性验证

## 问题复现与结论

KBD30880 坏候选的精确字段为 `signals[2].match.pattern=null`，Matcher 类型为 `exists`。原错误来自 JSON Schema anyOf，UI 又不展示 exists 的 pattern，因此专家不可见、不可改。删除失败不是同一个 Schema Bug，而是前端把全部暂存编辑合并后整份 PATCH；任一无效草稿都会阻断删除。
