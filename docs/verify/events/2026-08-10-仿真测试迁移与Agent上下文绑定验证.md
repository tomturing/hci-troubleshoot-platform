# 仿真测试迁移与 Agent 上下文绑定验证

对应需求：[仿真测试迁移与 Agent 上下文绑定需求](../../requirement/events/2026-08-10-仿真测试迁移与Agent上下文绑定需求.md)

对应方案：[仿真测试迁移与 Agent 上下文绑定方案](../../solution/events/2026-08-10-仿真测试迁移与Agent上下文绑定方案.md)

## 1. 验证边界

最终链路必须完全在 K3s 中：

```text
Admin UI
  → Simulation Control API/hci_sim DB
  → K3s hci-sim
  → Admin 创建仿真工单
  → Agent context
  → same-origin K3s terminal_bridge
  → K3s hci-sim
```

以下资源必须关闭或不可用，测试仍应完成：

```text
Custom UI 仿真入口
Windows terminal_bridge.exe
Linux Docker terminal_bridge
真实 HCI SSH
```

## 2. 代码与静态门禁

```bash
pnpm --dir frontend/admin test
pnpm --dir frontend/admin build
pnpm --dir frontend/customer test
pnpm --dir frontend/customer build
rg -n "仿真租约|simulation-connect|parseSimulationConnectionJson|executionMode.*sim-ssh" frontend/customer
```

验收标准：

- Admin 编译、类型检查、测试通过；
- Customer UI 真实 SSH 流程通过；
- Customer UI 不再出现仿真入口/文案/Lease parser；
- 共用组件没有反向依赖 Admin 私有代码。

## 3. Admin UI 功能验证

### 3.1 菜单和权限

1. 使用具备 `simulation:view` 账号登录 Admin UI。
2. 确认左侧显示“仿真测试”。
3. 使用无 `simulation:view`、无 `simulation:build`、无 `simulation:run` 的账号分别访问。

期望：无权用户看不到菜单或 API 返回 403，不依赖前端隐藏作为安全措施。

### 3.2 环境构建

| 案例 | 操作 | 期望 |
|---|---|---|
| B-01 | 输入合法已发布 KBD 23821，点击环境构建 | validating→building→ready |
| B-02 | 输入空值/字母/超长数字 | 前端提示，服务端 422 |
| B-03 | 输入未发布/不存在 KBD | failed，显示明确 capability/publish 错误 |
| B-04 | 构建中重复点击 | 同一 build 或 409，不创建重复 Runtime |
| B-05 | 构建失败后展开日志 | 日志可展开/关闭/复制脱敏摘要，可重试 |
| B-06 | 刷新页面/断开 SSE | 通过 build_id + after_seq 恢复，无日志丢失或乱序 |
| B-07 | KBD revision 在构建后变化 | build stale，开始测试置灰 |

### 3.3 开始测试门禁

验证以下状态下按钮均置灰：

```text
idle/validating/building/failed/cancelled/stale/expired
```

只有：

```text
build=ready + runtime=ready + bundle=published + lease=issuable
```

按钮才可点击。

## 4. TestRun → Agent Context 验证

### 4.1 绑定前置条件

点击“开始测试”后：

1. 创建唯一 TestRun；
2. 打开创建工单窗口；
3. 用户填写标题/描述；
4. 点击“连接 SSH 并创建工单”；
5. 创建/获取 Case 和 Conversation；
6. 绑定 TestRun 到 `case_id/conversation_id`；
7. 查询 context，确认包含：

```text
simulation=true
execution_mode=sim-ssh
support_id=23821
kbd_revision
bundle_digest
product=HCI
version=6.9.0
components=[虚拟机]
virtual_node_id
```

### 4.2 反向验证

| 注入 | 期望 |
|---|---|
| 不绑定 context 就启动 Agent | 阻断并显示 `TEST_RUN_CONTEXT_MISSING` |
| context 过期 | `TEST_RUN_EXPIRED`，不发命令 |
| bundle digest 不一致 | `BUNDLE_DIGEST_MISMATCH`，不发命令 |
| real + sim context 同时存在 | `EXECUTION_MODE_CONFLICT`，不发命令 |
| case 已被其他 TestRun 绑定 | 幂等返回或 409，不覆盖原绑定 |
| Lease 过期 | 重新签发新 Lease，不复用旧密码 |

## 5. K3s 三段链路验证

在 Admin UI 的同一页面完成：

```text
Admin UI WebSocket → /terminal-bridge
→ K3s terminal_bridge
→ hci-sim SSH
```

验收证据：

- 浏览器 WebSocket 101，同源 `/terminal-bridge`；
- Bridge `ssh.connected`、`exec.start`、`exec.done`；
- hci-sim `ssh.connected`、route 命中、`exec.done`；
- 同一 `test_run_id/exec_id/trace_id`；
- 无 Windows Bridge、Linux Docker Bridge 或真实 HCI 流量。

## 6. Agent KBD 23821 完整验证

### 6.1 正向

Scenario：`kbd-23821-positive-full`

期望执行顺序：

```text
sig_001 qkv_task
  → VM/HOST/END
sig_002 qfk_log
  → Completed SIZE1 of SIZE2，delta=0
expert qfk_system
  → expected keyword/state
Conclusion = DEFINITIVE / support_id=23821
```

验收：

- 每个 required Signal 有 `tool_call` 和 `tool_result`；
- 每个命令对应唯一 exec_id；
- produced variables 与 requires 关系正确；
- Signal outcome 全为 SATISFIED；
- Agent 输出根因只引用当前 KBD revision 的 solution；
- TestRun 结论标记 `simulation=true`，不计入真实 HCI 指标。

### 6.2 负向

Scenario：`kbd-23821-negative-ready-present`

期望：`ready` 出现，matcher 不满足故障条件；Agent 不输出 23821 根因。

### 6.3 不确定

Scenario：`kbd-23821-inconclusive-missing-log`

期望：qkv 可执行但 qfk_log 缺失/超时；结论为 `INCONCLUSIVE`，页面明确提示缺少证据，不得进入 S4 根因确认。

## 7. 迁移退场验证

```bash
rg -n "仿真租约|simulation-connect|recommended_command|connection.json" frontend/customer
```

同时关闭 Windows Bridge 和 Linux Docker Bridge，刷新 Customer UI，确认：

- Customer UI 无仿真入口；
- Admin UI 仿真测试仍可打开；
- Admin UI 只使用 K3s `/terminal-bridge`；
- 普通 Customer SSH 流程不被影响。

## 8. 稳定性/恢复验证

| 编号 | 场景 | 期望 |
|---|---|---|
| R-01 | Admin 页面刷新 | build/TestRun 状态和日志恢复，Lease 不泄露 |
| R-02 | 构建服务重启 | 已持久化 build event 不丢，状态可恢复 |
| R-03 | Bridge Pod 重启 | 当前 attempt 失败封闭，新 attempt 新 Lease 可运行 |
| R-04 | hci-sim Pod 重启 | Runtime 重新 ready，旧 Lease 不复用 |
| R-05 | hci_sim DB 暂不可用 | 仿真页面报错，主业务工单可用且不回退 |
| R-06 | 双击开始测试 | 只有一个 Case/TestRun |
| R-07 | 并发不同 KBD 构建 | 资源隔离、日志按 build_id 不串线 |
| R-08 | 超长构建日志 | 前端不 OOM，分页/游标正常 |

## 9. 通过/阻断规则

### 通过

- Admin 页面、权限、状态机和日志门禁通过；
- TestRun context 在 Agent 启动前可查询且 scope=APPLICABLE；
- K3s Bridge/hci-sim 分层证据完整；
- 23821 full positive、negative、inconclusive 三类结果符合预期；
- Customer UI 仿真逻辑移除，真实 SSH 回归通过；
- 所有恢复、权限和无依赖验证通过。

### 阻断

- 仍需打开 Custom UI 或 Windows Bridge 才能运行；
- Agent context 缺失却继续发命令；
- 只有 qkv_task 成功却宣称完整 23821 结论通过；
- synthetic 数据写入主库 environment 或真实统计；
- Build/Run 日志泄露 Lease/Secret；
- duplicate Case/TestRun、状态机倒退或旧 Lease 重用。

## 11. 浏览器闭环专项验证（2026-08-11）

### 11.1 自动化门禁

```bash

  src/views/__tests__/SimulationTestView.spec.ts \
  src/views/__tests__/ConversationProtocol.spec.ts
```

### 11.2 真实浏览器 KBD 27123

1. 使用 Chromium 打开 `http://172.28.24.21/admin/simulation`；
