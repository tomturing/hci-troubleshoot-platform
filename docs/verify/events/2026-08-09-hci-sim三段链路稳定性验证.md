## Linux 三段链路实测

运行实例（最新重签 Lease，含端口冲突回退验证）：

```text
hci-sim-c3-23821-20260809154400
test_run_id=run-23821-1786290265
SSH=172.28.24.21:22001（故意占用请求的 22000 后自动回退；无冲突时保留默认端口）
Linux terminal_bridge=172.28.24.21:9999
```

使用 `HCI_SIM_CONNECTION_JSON` 模式运行 `cmd/hci-sim-smoke`：

```text
PASS support_id=23821 test_run_id=run-23821-1786289623 ssh=connected exit_code=0 synthetic=true
```

随后以端口冲突回退实例的同一 `connection.json` 重跑，结果同样为：

```text
PASS support_id=23821 test_run_id=run-23821-1786290265 ssh=connected exit_code=0 synthetic=true
```

独立证据：

- Linux Bridge：`ssh.connected`、`exec.done`、`exit_code=0`。
- hci-sim：同一 `test_run_id` 的 `ssh.connected`、`exec.start`、`exec.done`、`signal_id=sig_001`。
- 返回业务状态 `failed` 是 KBD 23821 的预期模拟故障，不是传输失败。
- 未出现 `lease.rejected`、运行时端口冲突或 host key 错配；请求端口被占用时已按设计回退到隔离端口。
