# 可观测性页面布局微调、Grafana 权限及 SSH 交互 Bug 优化成果说明

我们已经成功完成了可观测性页面 Padding 对齐、Grafana 权限提升、SSH 自动关闭后闪退 Bug 以及 SSH 登录凭证保存功能的优化，并提交了 PR #402。

## 变更摘要

### 1. 可观测性页面 Padding 与 Margin 彻底对齐
- **使用 `!important` 强行重置**：在 [ObservabilityView.vue](file:///mnt/d/aihci/hci-troubleshoot-platform/frontend/admin/src/views/ObservabilityView.vue) 的样式中，将最外层容器 `.observability-container` 的 `padding` 和 `margin` 设置为 `0 !important`，同时将卡片 `.observability-card` 的 `margin` 重置为 `0 !important`。这使得在 Layout 框架自带的 20px 间距下，可观测性页面的大卡片四周间距（左、上、右）与“仪表盘”和“用户管理”页面完美保持一致。

### 2. 内嵌 Grafana 免密连接权限提升为 Admin
- **提升匿名用户角色权限**：在 `deploy/observability/docker-compose-obs.yml`、`deploy/helm/hci-platform-obs/templates/grafana.yaml` 和 `deploy/helm/hci-platform/templates/observability/grafana.yaml` 中，将匿名访问用户的权限角色 `GF_AUTH_ANONYMOUS_ORG_ROLE` 从 `Viewer` 提升为 `Admin`，彻底解决 `dashboards:read` 权限限制引发的 `Dashboard not found` 及读取权限不足报错，确保管理员在嵌入看板中无缝流式获取系统监控指标。

### 3. 技能管理副标题排版规范化（字体、引号统一）
- **中文字符双引号与字体继承**：在 [SkillManageView.vue](file:///mnt/d/aihci/hci-troubleshoot-platform/frontend/admin/src/views/SkillManageView.vue) 中，将副标题中的半角直角英文引号（`"过程性知识 + 诊断流程"`）替换为标准中文字符双引号 `“` 和 `”`，消除半角引号诱发的浏览器 Western font fallback 样式渲染冲突。
- **显式字体继承规约**：在样式块中为 `.page-desc` 和 `.standard-link` 显式追加 `font-family: inherit` 及 `font-weight` 规则，保证文本的字体及粗细与工具/SOP管理页面完全同步。

### 4. 修复客户端 SSH 连接成功后自动关闭弹框导致的闪退问题
- **前置连接状态保护**：修改 [SshConnectDialog.vue](file:///mnt/d/aihci/hci-troubleshoot-platform/frontend/customer/src/components/SshConnectDialog.vue) 中的 `handleCancel()` 函数逻辑，只有当 `viewState.value` 不等于 `success` 时才去主动断开连接。这防止了连接成功后，自动关闭弹框时触发 `@close="handleCancel"` 引起 `chatStore.disconnectSSH()` 被错误执行、掐断已有长连接会话的 bug。

### 5. 优化凭证输入框结构以稳定唤醒密码自动保存
- **提供 Name 与 Autocomplete 匹配**：修改了共享的 SSH 连接配置表单 [SshFormSection.vue](file:///mnt/d/aihci/hci-troubleshoot-platform/frontend/customer/src/components/SshFormSection.vue)，为“主机地址” (`name="host"` / `autocomplete="on"`)、“用户名” (`name="username"` / `autocomplete="username"`) 和“密码” (`name="password"` / `autocomplete="current-password"`) 输入框补充了标准的 HTML 表单属性，辅助浏览器密码管理器（如 Chrome / Edge Credential Manager）准确分析关联关系，提示用户保存密码并自动填充。

### 6. 文档归档
- **设计文档历史追踪**：在 [管理台设计.md](file:///mnt/d/aihci/hci-troubleshoot-platform/docs/solution/admin-ui/管理台设计.md) 的“变更历史”中补充记录了 `v0.37` 关于上述卡片布局对齐、匿名角色权限提升及技能副标题样式优化的记录。
