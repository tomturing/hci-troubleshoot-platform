## 必须由 GitHub runner 补充

- actionlint（当前容器未安装）；
- Go quality gate、race、vet、build；
- 动态 matrix 实际展开、GHCR push、Trivy SARIF 上传；
- database-only、hci-sim-only、backend-only main push 的完整 DAG；
- 20 次以上历史 run 的 P50/P95 观测。

## 合并验收标准

1. PR 的 required context 名称仍可正常汇总；
2. 无关 workflow 显示 `skipped`，不产生 runner；
3. backend-only 发布只更新对应环境服务；
4. 无 schema 变化时 `build-db-migrate` 为 skipped；
5. 任一 build/deploy job 超时后能在限定时间内结束，不留下 in-progress run。
