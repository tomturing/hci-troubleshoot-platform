# hci-sim 阶段 A：目录收敛与基础门禁验证方案

> **证据状态：pending。** 本文是阶段 A 实施后的验收计划，不是已经执行的验证报告；未附真实 Git SHA、命令输出和 CI 链接前，所有用例与结论均视为未通过。

关联[需求](../../requirement/events/2026-08-05-hci-sim阶段A目录收敛与基础门禁需求.md)、[方案](../../solution/agent/events/2026-08-05-hci-sim阶段A目录收敛与基础门禁方案.md)和[任务](../../task/agent/events/2026-08-05-hci-sim阶段A目录收敛与基础门禁任务.md)。

## 验证目标

证明仓库从两个实现收敛为唯一 `hci_sim/` 源码事实源，同时保持 `hci-sim` 对外资源名、现有构建/Helm/Bridge/真实 SSH 行为，并建立能阻止双实现和不安全能力回归的 CI。

## 范围与非目标

范围包括目录/引用/提交边界、Go 质量、Manifest/Helm、Bridge smoke、文档事实和反退化门禁。不验证阶段 B 的新 Runtime 协议、阶段 C Compiler 或阶段 D TestRun。历史 KBD 27123 E2E 只能作为回归参考，不能替代本次当前 SHA 的证据。

## 环境矩阵

| 环境 | 用途 | 必需记录 |
|---|---|---|
| 本地干净 clone | 文件、引用、Go/race、文档检查 | OS/arch、Git/Go 版本、SHA |
| CI PR | 门禁阻断性 | workflow/run URL、runner、cache 状态 |
| 容器/Helm render | 镜像和部署契约 | Docker/Helm 版本、image/chart digest |
| 隔离 dev namespace | sim smoke（若具备） | context、namespace、values digest |
| 真实 SSH 测试目标 | Bridge 非仿真回归（若获授权） | 授权、target alias、脱敏 trace |

不得把当前不存在的 namespace 写成已部署；缺少可选环境时相关用例为 `blocked`，不能记 PASS。

## 对抗性审查

- 用同名文件、symlink、嵌套 go.mod 和生成脚本引用尝试绕过旧目录扫描。
- 确认反退化规则区分 `hci-sim` 资源名与 `hci-sim/` 源码路径，避免误报导致规则被关闭。
- 在 PR 仅改 Bridge/Manifest/Chart，确认 race 和相关门禁仍触发。
- 模拟 CI cache 污染和干净 clone，结果必须一致。
- 在工作区预置无关修改，确认清理提交不覆盖或回滚用户改动。

## 退出标准

- VA-01～VA-14 全部 PASS；VA-15 当前事实完整且无误导。
- 无未登记旧源码消费者，无双实现/不安全能力回归。
- Go/race/Manifest/Helm/Bridge/真实 SSH（若适用）无未解释回归。
- CI 反例证明门禁能够失败，而非仅存在配置文本。
- 开发、测试、运维共同签署阶段 B Go；任何阻断项未关闭则阶段 A FAIL/BLOCKED。
