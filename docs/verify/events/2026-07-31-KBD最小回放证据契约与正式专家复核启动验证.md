## 关键断言

| 场景 | 断言 |
|---|---|
| 运行审计 | `metadata_json.replay_manifest` 使用精确 KBD resource revision/checksum，而非诊断结束时的 active revision。 |
| 隐私边界 | manifest 只保存环境/参数 hash 与 artifact `exec_id` 查找键，不保存 stdout、stderr、客户日志、变量或命令参数明文。 |
| Artifact 事实边界 | 即使某 Signal 有 artifact 引用，`readiness.replayable=false`，且保留 artifact 授权/执行 runner blocker。 |
| 未执行 Signal | 编译失败或依赖缺失不伪造 artifact 引用；Evidence readiness 为 `absent` 或 `partial`。 |
| 专家界面 | QKV/QFK 来源证据默认收起，位于各自 Signal 卡片所有采集、判定和高级字段之后。 |

## 事实边界

本验证仅证明代码级 manifest 和 UI 布局。它不证明 Terminal Bridge artifact 一定存在或可访问，也不证明 Evidence Replay、Execution Replay、真实客户环境执行、可信 reviewer actor、Expert Gold 或模型 Champion/Challenger 对比已完成。
