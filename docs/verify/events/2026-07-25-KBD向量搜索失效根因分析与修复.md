**类型**: root-cause-analysis + fix

## 一、问题现象

用户工单 Q2026072402782 描述的故障与 KBD27123 高度匹配，但 InvestigationAgent 未命中该 KBD，直接进入 fallback 推理模式。

\`\`\`

## 三、根因分析（第一性原理）

### 根因 1（直接触发，持续性）：`ZAI_BASE_URL` / `ZAI_API_KEY` 从未注入到 Pod

| 文件 | 事实 |
|------|------|
| `deploy/helm/.../configmap.yaml` | 无 `ZAI_BASE_URL`、无 `ZAI_API_KEY` |
| `deploy/helm/.../secret.yaml` | 无 `ZAI_API_KEY` |
| `deploy/helm/.../kb-service/deployment.yaml` | `envFrom: hci-common-config`，无独立 env 注入 |
| `backend/kb-service/app/config/__init__.py`（修复前） | `ZAI_BASE_URL` 默认 `http://host.docker.internal:18790` |
| 该默认值 | → OpenClaw 聊天网关，不支持 `embedding-3` → 必然失败 |

**后果**：

\`\`\`
embedding API → 400/连接失败 → 连续 3 次 → 熔断
  → numpy hash embedder 接管（SHA-256 种子随机向量）
  → hash(用户query) vs real_embedding(KBD27123) → cosine ≈ 0（随机）
  → KBD27123 不在 top-15 → 未命中
\`\`\`

这不是偶发故障，是**自上线起就持续存在的配置缺失**，被 hash 降级 + 假 `used_vector=True` 掩盖。

### 根因 2（结构性 Bug）：`_extract_user_query` 取最后一条 user 消息

多轮对话后最后一条消息往往是 `"①"` / `"继续"` / `"好的"`，而非症状描述。
用它做向量检索 query = 随机搜索。

### 根因 3（放大因素）：hash 降级时 `used_vector=True` 审计污染

hash 向量不是 `None`，代码判断 `query_vector is not None` → `used_vector=True`（假信号）。

### 根因 4（次要）：embedding 失败时降级 `published_at DESC`

`published_at DESC` = 时间倒序 = 随机排序，毫无语义。

## 四、修复内容

### Fix 1: `backend/kb-service/app/config/__init__.py`
`ZAI_BASE_URL/ZAI_API_KEY/ZAI_EMBEDDING_MODEL` → `LLM_BASE_URL/LLM_API_KEY/LLM_EMBEDDING_MODEL`

三个变量已在 `hci-common-config` + `hci-secrets` 中，字段名对齐后 Pydantic Settings 自动读取。

### Fix 2: `backend/kb-service/app/services/embedding.py`
- 新增 `embed_for_search()`：**禁止 hash 降级**，失败 → 抛异常 → 调用方走 BM25
- `embed_batch()`：保留 hash 降级（入库路径，不阻断 KBD 发布）
- `_embed_via_zai()` → `_embed_via_llm()`，引用 `LLM_*` 字段

### Fix 3: `backend/kb-service/app/routes/kbd_search.py`
- `embed_single()` → `embed_for_search()`
- 降级从 `published_at DESC` 改为 **BM25** (`tsv @@ plainto_tsquery('simple', :query)`)
- 日志新增 `search_path: "vector" | "bm25"` 字段，修正 `fallback` 字段值

### Fix 4: `backend/agent-service/app/adapters/agents/htp/investigation_agent.py`
`_extract_user_query`（取最后一条）→ `_build_retrieval_query`（正序取首条有效主诉，跳过控制符）

\`\`\`python
# 跳过 S0 控制符：①②...、纯数字、继续/好的/收到/确认/是/否
_CONTROL_RE = re.compile(r"^[\u2460-\u2468\d]+$|^(继续|好的|收到|确认|是|否|跳过|retry|skip|ok|yes|no)$", ...)
\`\`\`

### Fix 5: `deploy/helm/hci-platform/templates/configmap.yaml`
新增 `LLM_EMBEDDING_MODEL` 条目，值来自 `kbService.llmEmbeddingModel`（`values.yaml:251` 已定义）。
