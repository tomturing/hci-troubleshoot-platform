### 防复发判据

- 不能只断言 stdout/stderr 已筛选，必须枚举最终 HTTP schema 的所有字符串字段并检查聚合副本。
- 大请求保护必须发生在 `request.json()` 之前；Pydantic 校验只能保护业务层，不能保护 JSON 解码阶段内存。
- 命令 exit 0 只证明远端执行完成，不等于结果已回传、Agent 已消费或工具卡片已进入终态。
