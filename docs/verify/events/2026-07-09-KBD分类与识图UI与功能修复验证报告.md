## 验证步骤与用例

### 用例 1：验证列表页操作列排版
- **预期结果**：KBD 待审核/已发布列表页面操作列中，原有“重新分类”和“重新识图”文字按钮已彻底消失。操作列宽度自适应收缩（降至 220px 左右），留白更加合理，不会出现布局折行或拥挤现象。

### 用例 2：验证详情弹窗内的“重新分类”按钮
- **步骤**：
  1. 点击任意 KBD 数据的“详情”按钮，展开 KBD 详情弹窗。
  2. 观察“AI建议分类”标签右侧是否成功渲染 `Refresh` 图标按钮。
  3. 点击该按钮，应弹出 Element Plus 风格的美观确认弹窗（内容为“确认用最新 Prompt 重新分类「...」？”且完整展示标题，无截断）。
  4. 点击“确认”后，按钮显示 `loading`。接口请求返回成功后，弹窗内“AI建议分类”的标签、置信度和分类理由当场刷新，关闭详情后列表页的分类也同步更新。

### 用例 3：验证详情弹窗内的“重新识图”按钮
- **步骤**：
  1. 展开 KBD 详情弹窗，滑动到“内容预览”或“图片列表”部分的截图框。
  2. 确认截图卡片的 header 栏（例如“其他截图”右侧）成功渲染了 `Refresh` 图标按钮。
  3. 点击此图标按钮。**注意：点击时不应导致手风琴折叠面板收起或展开（事件已被 stopPropagation 阻止）**。
  4. 应弹出 Element Plus 风格确认框，提示重新识图耗时较长。
  5. 确认运行后，接口正常执行，执行成功后，详情内的内容预览及图片解析结果（`images_json`）即时完成重组并重新刷新渲染。
