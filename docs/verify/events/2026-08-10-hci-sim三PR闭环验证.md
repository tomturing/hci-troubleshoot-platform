### 两步人工验收（当前实现契约）

1. 在 Admin UI 打开“仿真测试”，输入 KBD_ID，点击“环境构建”；必须看到构建进度和可展开日志，失败后重试且 KBD_ID/标题/描述仍保留。控制面返回的 connection 必须显示 `execution_mode=sim-ssh`、端口 2222、用户 `sim`、TestRun ID 和 Bundle digest。
2. 点击“开始测试”，补充标题和描述，点击“连接 SSH 并创建工单”；API 必须返回同一个 TestRun ID，且不得出现真实 HCI host/lease。若 K3s/Control Plane/Bundle 任一依赖未注入，页面必须显示明确错误并保持输入，不得降级到真实 HCI。
