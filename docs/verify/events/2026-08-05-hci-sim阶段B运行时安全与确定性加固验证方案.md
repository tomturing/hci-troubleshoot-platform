# hci-sim 阶段 B：运行时安全与确定性加固验证方案

> **证据状态：pending。** 本文是阶段 B 验收计划，不代表 Manifest v2、Lease v2 或 Runtime 加固已经实现。每个用例必须在阶段 A 唯一源码基线上执行并附原始证据。

关联[需求](../../requirement/events/2026-08-05-hci-sim阶段B运行时安全与确定性加固需求.md)、[方案](../../solution/agent/events/2026-08-05-hci-sim阶段B运行时安全与确定性加固方案.md)和[任务](../../task/agent/events/2026-08-05-hci-sim阶段B运行时安全与确定性加固任务.md)。

## 验证目标

从协议、实现和对抗负载三层证明：Runtime 的身份、路由、exec/shell、故障、取消、输出和可观测性都进入同一个强约束执行内核；错误 Fixture、过期能力和资源攻击必须显式失败，且真实 SSH 模式不回归。

## 环境与测试层级

| 层级 | 环境 | 关注点 |
|---|---|---|
| L0 静态 | 干净 clone/CI | schema、lint、vet、secret/log、高基数 label |
| L1 单元/属性 | Go race/fuzz | parser、RouteKey、LeaseStore、fault、quota |
| L2 协议 | in-process SSH + Redis | auth、exec/shell、exit、cancel、CAS |
| L3 集成 | Bridge + Runtime + OTel | mode、trace、输出预算、清理 |
| L4 对抗/负载 | 多副本、受限资源 | queue、timeout、revoke、串线、重启 |
| L5 回归 | 授权 real SSH | real path 无仿真误标/协议回归 |

每次记录 Go/Redis/Bridge/Runtime 版本、Manifest/镜像 digest、seed、资源限制和网络策略。

## 对抗性组合

单用例通过后必须组合验证：长连接 + expiry + queue full；revoke + shell；output overflow + disconnect；timeout storm + cancel；Runtime 重启 + Redis quota；两个 Bundle 相同命令不同 scenario；real host substring + sim target alias。组合失败不得用单项通过覆盖。

## 回归范围

- 阶段 A 全量 Go/race/Manifest/Helm 门禁；
- Terminal Bridge 真实与 sim 两种模式；
- 现有 Lease/Fixture 单测及历史 KBD 27123 smoke；
- 生产 Tool Contract 命令编译；
- OTel exporter 不可用时的业务降级，不能因观测失败放宽授权。
