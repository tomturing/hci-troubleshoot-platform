# 修复 SOP 提交变量值按钮失效问题验证报告

## 变更说明

### 1. 后端变更
- **`conversations.py`**：在 Pydantic 请求模型 `InteractiveResponseBody` 中新增 `metadata: dict | None = None` 可选属性，并在 `submit_interactive_response` 路由中接收并向后传递该参数。
- **`conversation_service.py`**：
  - 更新了 `submit_interactive_response` 的签名以支持 `metadata` 传参。
  - 添加针对 `variable_input` / `variable_confirm` 两种交互种类的拦截。
  - 从 `metadata` 中取出 `variable_name`，从 `outcome` 中计算出填入的变量值。
  - 调用 `SopExecutionRepository.set_variable` 自动写入 SOP 的变量缓存池。
  - 成功写入后自动将执行状态设置回 `active` 并清空等待标记。
  - 将用户填入的值以 `user` 角色创建对话消息并持久化到消息库，以保证历史聊天记录正确且不出现空白消息。

### 2. 前端变更
- **`MessageBubble.vue`**：
  - 更新 `handleInteractiveFreeText` 和 `handleInteractiveOption`。
  - 提交 POST 请求时将事件原生的 `kind` 和 `metadata` 封装到 Payload 中。
  - 接口响应成功后，对于 HTP Agent 变量类事件，直接触发 `chatStore.sendMessage` 向后台传递变量值。
- **`InteractiveRequestCard.vue`**：
  - 更新 `doSubmit` 请求体，增加 `kind` 和 `metadata` 属性，消除未来可能暴露的同类缺陷。
