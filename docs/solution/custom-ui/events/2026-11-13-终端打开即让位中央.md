# 终端打开即让位中央

## 变更历史

| 日期 | 版本 | 变更内容 | 关联事件文档 |
|------|------|---------|------------|
| 2026-11-13 | v1.0 | 初版：让位条件由「日志收集 + 终端」放开为「终端可见」；互斥判定补 `centerHidden`，1080 / 1366 屏不再吞面板；让位态隐藏拖拽手柄 | — |

## 一、现场反馈

2026-11-13 客户现场（远程桌面，1080 宽视口）两张截图：

1. 日志收集展开、终端未连接：中央排障窗口 520px 左右，符合预期；
2. 点顶栏「SSH终端」后：**日志收集面板消失**，中央排障窗口仍在，xterm 只剩约 560px（≈60 列）。

用户原话：「之前的实现是 SSH 终端弹出会覆盖中间的排障窗口，现在是中间的排障窗口一直都存在」。

用户在自己机器（1920 全屏）复测，打开日志收集会自动并排终端、中央收成 0 宽，表现正常——
说明代码逻辑本身能跑通，问题只在特定宽度下才暴露。

## 二、根因（两个缺陷叠加）

### 2.1 让位条件过窄

```text
isAgentChatHidden = logCollectVisible && isTerminalVisible
```

首版（v0.53，2026-10-29）之所以要求日志收集同时打开，是为了表达「日志收集与 Agent 不联动」，
但把「让位」和「不联动提示」绑成了同一个开关。后果：单开终端时中央继续占 520px。
旧版右栏是 `el-drawer` 浮层，打开终端会**盖住**中央，所以从不暴露；面板化成 flex 三栏后，
中央变成抢像素的邻居，观感就退化成「终端开了，中间那块还杵着」。

### 2.2 互斥判定漏传 `centerHidden`

`enforceOverlayExclusive('right')` 用「两侧都开」求解，但没传 `centerHidden`，于是
1024~1439 这一段按常规三栏算（需要 `420 + 560 + 460 = 1440` 才够），必然判成 `overlay`：

- 打开终端 → 判定放不下 → `logCollectVisible = false`（面板被关掉）；
- 关掉后只剩右栏 → `slide`，中央又回到 520px。

两件事拼起来就是现场第 2 张截图：面板消失 + 中央回来了 + 终端被挤在 560。
`watch(logCollectVisible)` 里的自动切终端判定有同样问题，导致 1080 屏永远不会自动并排。

## 三、修复

1. **让位条件改为「右栏终端页签可见」**：`isCenterCollapsed = isTerminalVisible`。
   右栏被 SFTP 文件下载占用时仍不让位——传文件不需要 xterm 列宽，藏了中央只剩空白。
2. **互斥与自动切终端的求解都补 `centerHidden: true`**：按「打开后的最终形态」判定。
   1024~1439 双开是压缩布局（两栏共占整屏），互斥只保留给真正的一次看一块（<1024）。
3. **让位态隐藏拖拽手柄**：`PanelShell` 新增 `resizable`，`centerHidden` 时传 `false`。
   否则 1080 屏单开终端是 1032 宽，拖一下会被 `rightMax` 压到 520，看起来像手柄失灵。

求解结果（`centerHidden = true`）：

| 视口 | 左栏 | 右栏 | 中央 |
|------|------|------|------|
| 1080 单开终端 | 48（图标条） | 1032 | 0 |
| 1080 双开 | 497 | 583 | 0 |
| 1366 双开 | 628 | 738 | 0 |
| 1920 双开 | 880 | 1040 | 0 |

## 四、验收

单元测试（`frontend/customer`）：

- `chat.log-collect-focus.spec.ts`：单开终端让位、1080 双开铺满、1080 采集中点终端不关面板、
  900 窄屏仍互斥、SFTP 占用不让位、关日志不收终端、收起终端中央恢复、切走页签中央恢复；
- `chat.log-collect-case.spec.ts`：1280 双开改为「共存」，新增 900 双向互斥两条；
- `App.log-collect-focus.spec.ts`：`is-center-hidden` 与 `v-show` 契约、提示条只在未让位时出现、
  源码断言「0 宽而非 display:none」「让位态不渲染拖拽手柄」。

手工验证：在 1080 与 1920 两个宽度各走一遍
「开日志收集 → 点 SSH终端 → 收起终端」，确认面板不再被关、中央能恢复、会话草稿还在。
