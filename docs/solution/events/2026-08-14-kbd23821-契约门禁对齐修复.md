# KBD 23821 仿真契约门禁对齐修复

**日期**: 2026-08-14
**关联**: PR #757, PR #755
**标签**: agent:zcode, env:dev:sf

## 问题背景

KBD 23821（虚拟机-015 虚拟机集群内热迁移失败）仿真测试失败，错误信息：

> 分类 虚拟机-015 下的 KBD 均未通过自动执行契约

## 根因分析

PR #755 实现了校验器驱动门禁方案，核心设计：

- `validate_publishable_signals_json` 作为顶层门禁，决定 Signal 是否可执行
- `tool_contract_revision` 字节哈希仅作变化探测和追溯，**不阻断执行**

但 `hci_sim_resolver.py` 中遗漏了第二处门禁逻辑，仍在使用字节哈希比对阻断仿真绑定。

## 修复内容

### hci_sim_resolver.py 门禁对齐

**文件**: `backend/kb-service/app/services/hci_sim_resolver.py`

```python
# 修复前：字节哈希不匹配即阻断
elif tool_revision != current_tool_contract_revision():
    gaps.append(CapabilityGap("TOOL_CONTRACT_STALE", "..."))

# 修复后：仅追溯，不阻断
tool_revision = str((publish_validation or {}).get("tool_contract_revision") or "")
if not tool_revision:
    gaps.append(CapabilityGap("TOOL_CONTRACT_REVISION_MISSING", "..."))
# tool_contract_revision 仅作追溯，staleness 不阻断
```

### 测试用例更新

**文件**: `backend/kb-service/tests/test_hci_sim_resolver.py`

- 使用合法的 64 字符 hex 格式
- 验证 stale tool contract 不再阻断仿真绑定

## 设计对齐

按照 #755 校验器驱动最优解：

| 检查点 | 用途 | 行为 |
|--------|------|------|
| `validate_publishable_signals_json` | 顶层门禁 | 决定 Signal 是否可执行 |
| `tool_contract_revision` | 追溯字段 | 仅作变化探测和版本追溯，**不阻断** |
