# 工单排障诊断系列缺陷修复实施计划

本计划旨在彻底解决在分析工单 `Q2026060555810` 过程中发现的 5 个核心短板：
1. **SOP 节点字段不一致（SOP 导航失效导致 user_input 无法渲染）**
2. **分布式 Trace ID 继承与流式传输传播断裂**
3. **复合工具执行器缺少 `conversation_id` 关键字参数导致 acli 执行报错**
4. **决策树导航失效导致变量池 context_variables 无法更新**
5. **Prompt 审计 has_sop 贪婪匹配判定逻辑过于宽泛**

---

## User Review Required

> [!IMPORTANT]
> 1. **字段兼容处理**：在导航工具 `get_sop_node` 中，我们将同时支持 `node_id`/`id` 和 `name`/`title` 字段，以对齐数据库与内存结构，向下兼容。
> 2. **Trace ID 继承与 Header 显式注入**：我们将在 `create_conversation` 中通过 SQL 显式查询工单 trace_id 并继承；由于 Starlette 流式响应会重置 ContextVars 导致 httpx 链路丢失，我们在 `AgentClient.stream` 中手动组装 `traceparent` 请求头强行注入到下游，实现 100% Trace 穿透染色。
> 3. **关键字参数强传递**：在 `react_engine.py` 和 `sop_tools.py` 的工具执行与转发点，显式传递 `conversation_id` 命名关键字参数给执行器。
> 4. **数据库精准 has_sop 推断**：在 `PromptAuditService` 中，通过查询 `sop_execution` 记录是否存在，代替原本单纯的正则/字符串包含检测，彻底解决 S0 阶段 has_sop 被误置为 true 的问题。

### 2. Conversation-Service 链路追踪 ID 继承与 Traceparent 强注入

#### [MODIFY] [conversation_service.py](file:///aihci/hci-troubleshoot-platform/backend/conversation-service/app/services/conversation_service.py)
- 修改 `create_conversation()`，在创建时显式查询工单 Trace ID 并继承：
  ```python
  # 查询 Case 的 trace_id
  from sqlalchemy import text
  res = await self.repository.session.execute(
      text('SELECT trace_id FROM "case" WHERE case_id = :case_id'),
      {"case_id": case_id}
  )
  case_row = res.fetchone()
  case_trace_id = case_row[0] if case_row else None
  
  trace_id = case_trace_id or get_current_trace_id()
  conversation = await self.repository.create_conversation(
      case_id=case_id, trace_id=trace_id, assistant_type=assistant_type, metadata=metadata
  )
  ```

#### [MODIFY] [agent_client.py](file:///aihci/hci-troubleshoot-platform/backend/conversation-service/app/services/agent_client.py)
- 在 `AgentClient.stream(...)` 中，为了彻底解决 Starlette 流式生成器重置/丢失 OTel Context 导致下游 Trace ID 分叉问题，采用显式 `traceparent` 请求头注入机制：
  ```python
  import secrets
  # 优先获取当前上下文中的 Trace ID，若无则使用 session_id 作为 fallback 派生
  from shared.observability.otel import get_current_trace_id
  active_trace_id = get_current_trace_id() or secrets.token_hex(16)
  span_id = secrets.token_hex(8)
  
  headers = {
      "traceparent": f"00-{active_trace_id}-{span_id}-01",
      "Content-Type": "application/json"
  }
  
  # 在请求时显式传入 headers
  async with httpx.AsyncClient(timeout=None) as client, client.stream("POST", url, json=payload, headers=headers) as resp:
  ```
