## 一、需求来源

另一会话（2026-11-10 03:25~03:52 UTC）由现场工单 `Q2026111000243` 引出：P1 直传的 885,094,930 字节归档包已落到 5888，平台却在上传结束前回查，把「暂时查不到」写成终态失败。用户由此提出三层要求：

1. 页面能直接查 5888 的上传进展（`GET /upload_status/<upload_id>` 本来就有真进度，但 P1 的 `upload_id` 只在节点 acli 进程里，平台拿不到）；
2. admin-ui 菜单 `日志收集场景` → `日志收集`，放到「可观测性」下面；
3. 新增子页面放在【默认场景】左边，查看所有 P1/P2 工单的日志上传情况，字段清单先确认。

## 二、已确认的 4 项决策（2026-11-10）

| # | 决策 | 落地方式 |
|---|---|---|
| 1 | 显示客户名，同时显示 `client_id`；平台目前没有客户名数据，但数据库设计要支持「有工单就能从另一个系统查到客户名称」，可暂时为空 | **不新增列**。`"case"` 表早有 `customer_id uuid` 外键，`customer` 表有 `name` / `short_name` / `code`（注释明写「对应外部系统客户 ID」）。列表 `LEFT JOIN` 取 `COALESCE(short_name, name)`，空值显示「未关联客户」；`client_id` 单独返回。外部系统按 `customer.code` 导入并回填 `case.customer_id` 即可，避免两处存名字的双源漂移。staging 实测 712 工单、`with_customer=0`、`customer` 表 0 行 |
| 2 | 列表 10s 自动刷新；真实进度只对进行中的行按 30s 查 5888 | 列表接口**完全不查 5888**；独立 `destination-progress` 端点，前端只对 `status in (collecting/packaging/uploading)` 或 `delivery_status in (queued/pulling/uploading/relaying)` 的行分批（并发 5）查询；后端再加 10s TTL 缓存 |
| 3 | admin 只读 | 新端点只有 GET，网关只挂 `require_admin`；不提供重新核验/终止/重传，详情抽屉只读，只给复制路径、不给删除命令 |
| 4 | 不需要导出 CSV | 不做导出按钮与端点 |

## 三、实现

### case-service

- 新增 `app/routes/log_collect_admin_tasks.py`（前缀 `/internal/log-collect/admin/tasks`，`require_admin_token`）：
  - `GET ""`：跨工单分页 + 汇总计数（总数/传输中/已交付/未核验/失败，P1/P2 分列复用同一口径）；筛选走 bind params，枚举白名单；SQL 只读。
  - `GET /{task_id}/destination-progress`：P1 按产物名查 5888 `/upload_progress?filename=`，P2 用 `relay_upload_id` 查 `/upload_status/`；会话按 `start_time` 与 `task.created_at` 对齐并排除平台代传会话，防止把上一轮的 100% 当成本轮。
- `SangforRelayClient.upload_progress()`：404 就地降级为 `unsupported`，**平台可以先于 5888 发布**（重启 5888 的窗口不该阻塞平台上线）。
- 所有异常降级为 `no_record` / `unsupported` / `unavailable`，**不写任何任务状态**；只有 `status=done + target_path` 才是强证据。

### api-gateway

- `tasks_router`（`/api/v1/log-collect/admin/tasks`，`require_admin` + 内部令牌重签），只挂 GET；`_request_upstream` 增加原始 query 透传（不二次编码）。

### admin-ui

- 菜单 `日志收集场景` → `日志收集`，`order 5.6` → `4.1`（紧跟可观测性 4，排在 DSH 诊断 4.5 前）；同步 `adminMenu.spec`。
- 页签顺序 `日志上传 | 默认场景 | 自定义场景`；新页 `LogUploadPanel.vue` 含汇总条、筛选器、列表列、只读详情抽屉；10s/30s 定时器在卸载时清理。
- 「日志服务器真实进度」列只陈述观测：收妥（sha256 一致）／已收到 x/y（n%，第 a/b 片）／暂无记录／不支持进度查询／暂时不可用。
