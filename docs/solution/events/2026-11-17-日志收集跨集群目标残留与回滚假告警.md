# 2026-11-17 日志收集跨集群目标残留与回滚假告警方案

## 背景与需求

见 [需求事件文档](../../requirement/events/2026-11-17-日志收集跨集群目标残留与回滚假告警.md)。

## 方案概述 (WHAT)

1. 前端监听会话主机 `nodeIp`，切换集群时清空 `hostOptions` 并把 `form.ips` 重置为 `all`。
2. bridge `rollbackSpcAll` 只对 `written=true` 的主机执行回滚。

## 详细设计

### 前端：会话切换即作废旧集群目标

`LogCollectPanel.vue` 中，`selectedHosts` 完全由 `form.ips` 派生，勾选框只渲染当前 `hostOptions`。原实现 `applyCatalog` 只覆盖 `hostOptions`，不清理 `form.ips`，导致旧集群 IP 在界面上不可见却仍被提交。

新增：

```ts
watch(nodeIp, (next, prev) => {
  if (next === prev) return
  hostOptions.value = []
  form.ips = 'all'
})
```

- `nodeIp` 来自当前 SSH 会话主机，是"集群身份"的唯一真值。
- 只在会话主机变化时重置；同一会话重新探测（probe 刷新）不受影响，用户已选内容保留。

### bridge：回滚只针对已写入主机

```go
func (b *Bridge) rollbackSpcAll(s *SSHSession, st *spcTaskState, reason string, targets []string) (int, int) {
    // Targets 只包含 written=true 的主机
}
```

调用处从 `results` 过滤 `Written == true` 的 IP 传入。`written=0` 时传入空列表，`restoreSpcHosts` 不执行任何 SSH，`restored=0 / restoreFailed=0`，不再追加"可能残留平台清单"。

`restoreSpcTask` / `handleSpcRestore` 属于正常生命周期恢复（平台显式恢复、任务恢复），目标仍是全部节点，不改。

## 决策依据 (WHY)

| 方案 | 优点 | 缺点 | 评分 |
|---|---|---|---|
| A. 会话切换重置 + 回滚按 written 过滤（选中） | 从源头消除跨集群残留；回滚语义准确 | 手填的旧集群 IP 在切换会话时也会被清掉（符合预期） | ★★★★★ |
| B. 提交前校验 IP 必在当前列表 | 能拦住残留 | 会破坏"手填集群外 IP"的兜底能力 | ★★☆☆☆ |
| C. 仅前端重置 | 改动小 | 假告警仍在 | ★★★☆☆ |
| D. 仅后端回滚过滤 | 改动小 | 跨集群误下发依旧发生 | ★★☆☆☆ |

## 影响范围

- `frontend/customer/src/components/LogCollectPanel.vue`：会话切换重置。
- `terminal_bridge/log_collect_spc_fanout.go`：回滚目标过滤。
- bridge 改动需重建 exe 并现场人工重装；前端改动随前端发布生效。

## 风险与缓解

| 风险 | 影响 | 概率 | 缓解 |
|---|---|---|---|
| 会话重连误判为切换集群 | 已选目标被重置 | 中 | 仅在 `nodeIp` 值变化时重置；同值不触发 |
| 手填集群外 IP 在切换会话后丢失 | 用户需重填 | 低 | 符合"切换集群旧选择作废"语义 |

## 验收标准

- [x] 跨集群切换后不再提交旧集群 IP（前端行为级用例：换会话主机后 `form.ips` 回到 `all`，无 25.x 残留）。
- [x] 未写入节点不产生"可能残留平台清单"（`spcWrittenTargets` 单测：全未写入返回空列表）。
- [x] 已写入节点回滚失败仍正确提示（`restoreFailed > 0` 汇聚逻辑未改动，沿用既有 `spcCountRestore`）。
- [x] 前端单测 + Go 全量测试 + docs 门禁通过。
- [ ] 现场重装 exe 后跨集群切换实测（bridge 改动不自动到达客户机）。

## 测试策略

- 前端：真实交互链路（探测 → 取消勾选一台 → 换会话主机 → 再探测新集群），断言勾选框退场、手填框值为 `all`、新集群仍为全选。已做变异验证：删掉 `form.ips = 'all'` 该用例即变红。
- bridge：`spcWrittenTargets` 单测覆盖「部分写入」「全部未写入」「空输入」三种输入，确保回滚目标不含未写入主机。
- 本地不覆盖：真实 SSH 部分失败时的回滚提示文案，需现场重装 exe 后验证。
