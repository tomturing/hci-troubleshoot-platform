# 智能体变量池微内核架构重构与目录文档更新设计方案

本方案旨在对 `agent-service` 的变量池管理（`variable_pool.py`）进行彻底的架构重构：采用**控制与执行解耦的微内核架构（Microkernel Architecture）**，以规避潜在的循环导入风险与职责膨胀；同时更新并更名后端的目录结构设计文档。

---

## 1. 架构目标与设计理念

我们将当前的大文件 `variable_pool.py` 分拆并重构为高内聚、低耦合的 `variable_pool/` 包结构，建立明确的物理边界：

```
memory/variable_pool/
├── __init__.py           # 外观层（Facade）：导出外部所需的公共 API，提供 100% 向后兼容性
├── pool.py               # 存储与状态核心（State Plane）：定义 VariableRequestResult 及工作记忆读写交互
└── engine.py             # 策略决策内核（Control Plane）：JIT 调度器，执行策略路由决策（无状态，通过 executor 调用动作）
```

- **控制面与执行面分离**：`engine.py` 仅负责流程与策略决策控制（例如：决策应该走 `tool_call` 还是 `user_confirm`，并在内存中进行缓存检查和状态校验）。具体的执行动作完全委托给无状态的 `tool_executor`（执行面/数据面）与 `conversation_sop_client`（交互与中断层）。
- **零破坏性变更**：外观层（`__init__.py`）保持暴露原汁原味的 `VariableRequestResult` 和 `sop_request_variable`，确保与外层 `app/memory/__init__.py` 以及 `adapters/agents/htp/` 完全无缝向后兼容，所有测试 100% 绿灯通过。

## 2. 拟修改与创建的文件

### 2.1 智能体变量池包 (backend/agent-service)

#### [NEW] [__init__.py](file:///mnt/d/aihci/hci-troubleshoot-platform/backend/agent-service/app/memory/variable_pool/__init__.py)
* 作为包外观（Facade），提供 100% 兼容的接口桥接：
  ```python
  from app.memory.variable_pool.pool import VariableRequestResult
  from app.memory.variable_pool.engine import sop_request_variable

  __all__ = ["VariableRequestResult", "sop_request_variable"]
  ```

#### [NEW] [pool.py](file:///mnt/d/aihci/hci-troubleshoot-platform/backend/agent-service/app/memory/variable_pool/pool.py)
* 承载 **Memory Core**（工作记忆存储/状态面定义）。
* 迁移并封装 `VariableRequestResult` 数据类，确保属性与强类型设计。
* 独立并提供纯粹的 Memory State 状态校验、缓存检查和中断状态封装函数。

#### [NEW] [engine.py](file:///mnt/d/aihci/hci-troubleshoot-platform/backend/agent-service/app/memory/variable_pool/engine.py)
* 承载 **JIT 决策内核**（策略控制面）。
* 迁移 `sop_request_variable` 函数作为核心控制流程：
  - 检查 context 缓存与并发请求锁。
  - 获取 SOP Schema 定义并解析。
  - 路由决策：`env_injection` 拦截、`sop_default` 静态处理、`tool_call` / `user_confirm` / `user_input` 挂起控制。
  - 调用外部透传的无状态执行器（`tool_executor`）与交互客户端（`conversation_sop_client`）以获得具体返回值。

#### [DELETE] [variable_pool.py](file:///mnt/d/aihci/hci-troubleshoot-platform/backend/agent-service/app/memory/variable_pool.py)
* 彻底删除旧版单文件，其职责已被上述微内核结构完全分流并优雅解耦。
