# SOP 决策树渲染与详情弹窗优化方案

本文档提供了对超融合故障诊断平台（HCI Platform）中 SOP 管理模块“SOP 文档详情”弹窗进行优化与决策树结构渲染的完整实施方案。

## 目标与背景

用户反馈当前环境在展示 SOP 文档详情时存在两个主要问题：
1. **决策树结构无法正常显示**：由于深度嵌套导致卡片被严重挤压。
2. **详情弹框尺寸有限，没有自适应也不支持手动调节**：原有弹窗固定 `760px` 宽，展示大型复杂决策树时极为局促。

**优化方案的核心点：**
- **自适应与高阶交互能力**：弹窗重构为大尺寸（`width="90%"`，最大 `1400px`），开启 Element Plus 的拖拽功能（`draggable`），并新增**全屏切换模式**以适应复杂诊断流的查看。
- **防止嵌套挤压的扁平树节点结构**：将子节点渲染在父节点卡片的外部（下方），仅通过 `border-left` 的虚线和 `24px` 的 padding 进行层级缩进，而非在父节点卡片内无限嵌套。这样每个层级的可用宽度差异极小，彻底解决挤压问题。
- **极致的视觉美感**：左侧分栏展示 SOP 基础元数据，右侧分栏作为树的展示区；对前置条件、变量表格、诊断命令、快速恢复（Amber/闪电图标）、彻底解决（Emerald/护盾图标）进行高端卡片化排版，配合代码高亮、一键复制和微动画效果。
- **一键控制**：提供“全部展开”和“全部折叠”按钮，通过响应式 `Set` 追踪展开状态，实现 100% 响应式瞬时渲染。

## 2. 具体设计实现详情

### 2.1 扁平缩进式递归树结构设计 (SopTreeNode)
子节点与父节点同级排列，避免容器宽度逐级缩水：
```
+----------------------------------------------------+
|  [H1 场景根节点] L1                              [展开] |
+----------------------------------------------------+
  |
  +-- [H2 路由节点] L2 (Indentation: 24px)
  |   +----------------------------------------------+
  |   |  过滤条件: 存储类型为分布式                      |
  |   +----------------------------------------------+
  |     |
  |     +-- [H3 叶子节点] L12 (Indentation: 48px)
  |         +----------------------------------------+
  |         |  acli 命令: acli storage pool show     |
  |         |  快速恢复: 重启集群                     |
  |         +----------------------------------------+
```

### 2.2 premium 卡片样式与视觉规范
- **控制按钮与标题栏**：决策树标题右侧配有简洁高阶的控制栏（全部展开/折叠，全屏切换，节点总数微型圆徽标）。
- **命令行终端（acli）**：使用深灰色背景（`#1e293b`），亮绿色字体（`#10b981`），等宽字体，右上角带有一键 Copy 的微型悬浮按钮，带有交互 hover 的微动画。
- **快速恢复 vs 彻底修复**：
  - 快速恢复（临时方案）：警告级背景色，佐以 Amber 调色和 `Lightning` 电光图标。
  - 彻底修复（根治方案）：成功级背景色，佐以 Emerald 调色和 `ShieldCheck` 护盾图标。

## 3. 验证与回归测试计划

### 3.1 自动与手动验证
1. **测试接口**：在弹窗打开时，触发 `/api/v1/sop/{id}/tree` 并验证响应状态码及树节点的层级结构。
2. **折叠/展开测试**：
   - 验证默认情况下决策树全部展开是否正确显示。
   - 点击“全部折叠”按钮，确认仅保留根节点卡片。
   - 点击“全部展开”按钮，确认完整层级瞬时重现。
3. **尺寸与拉伸测试**：
   - 改变浏览器视口宽度，测试 `90%` 的弹窗在不同屏幕下的响应式呈现。
   - 尝试拖拽弹窗标题，验证 `draggable` 是否生效。
   - 点击全屏按钮，验证是否无缝切换为满屏状态。
4. **节点渲染回归**：
   - 仔细对比 `disk_lifetime_anomaly` 等包含警告的复杂 SOP 文档，确认 variables 表格、prerequisites 列表、acli 深色框在全部展开时均能以优雅的宽度呈现，绝不发生折叠或字字重叠的诡异效果。
