# 顶栏四个入口按钮底色统一

## 一、现象

顶栏右侧四个入口（工单信息 / 关闭工单 / 日志收集 / SSH终端）看起来是四种底色：

- 工单信息：半透明浅蓝白
- 关闭工单：接近纯白的实底
- 日志收集：el-button 默认白底 + 深灰字（**这一处没有任何自定义样式**）
- SSH终端：半透明绿

## 二、根因（不是"四个值没对齐"这么表面）

原样式在 `App.vue` 里分散成四段：

| 按钮 | 原背景 | 原字色 |
|---|---|---|
| `.case-info-btn` | `rgba(255,255,255,.2)` | `#fff` |
| `.close-btn` | `rgba(255,255,255,.9)` | `#337ecc` |
| `.log-collect-btn` | **未定义** → 落到 el-button 默认白底 | 默认深灰 |
| `.terminal-btn` | `rgba(103,194,58,.3)` | `#fff` |

两个更深的原因：

1. **`log-collect-btn` 压根没有样式规则**，靠 el-button 默认值兜底，所以最难被发现——
   它不是"设计成另一种颜色"，而是"漏了"。
2. **顶栏背景是 `linear-gradient(135deg, #409eff, #337ecc)` 的横向渐变**。
   半透明层叠在渐变上时，同一个 `rgba` 在左侧（#409eff）和右侧（#337ecc）合成的颜色不同，
   因此**即使把四个按钮写成同一个 rgba，肉眼看到的仍然不止一种颜色**。

推论：想让四个按钮真正一致，只能用**不透明色**。

## 三、方案

新增统一基底类 `.header-btn`，四个按钮共用：

```css
.header-btn {
  background: #ffffff !important;
  border: 1px solid #ffffff !important;
  color: #2b6cb0 !important;   /* 白底对比度 5.38:1，达 WCAG AA */
  font-size: 12px !important;
  font-weight: 500 !important;
  box-shadow: 0 1px 2px rgba(0, 0, 0, 0.08);
}
.header-btn:hover { background: #ecf5ff !important; border-color: #ecf5ff !important; }
.header-btn:focus-visible { outline: 2px solid #fff; outline-offset: 2px; }
```

几个刻意的取舍：

- **悬停色只绑 `:hover`，不绑 `:focus`**：按钮被点过会保留焦点，Element Plus 也会给
  `:focus` 上 hover 色，结果是"点过的那个按钮一直和另外三个颜色不一样"。
- **键盘可达性只加白色描边**，不改底色，避免出现"焦点态 = 第五种颜色"。
- **删除 `.terminal-btn :deep(.el-icon){margin-right:4px}`**：那条规则写在非 scoped
  `<style>` 里，`:deep()` 不会被编译，实际从未生效；保留它只会让后来者误判图标间距。
- **不动 `el-popover` 的引用结构**：工单信息按钮仍是 popover reference，只加类。

## 四、以后新增顶栏按钮

1. 模板上必须带 `header-btn`；
2. 不要在按钮自己的语义类里写 `background` / `color` / `border`，差异只能靠图标与文案；
3. `src/components/__tests__/App.topbar-buttons.spec.ts` 会守住这两点
   （四个按钮都挂 `header-btn`、单个按钮不得自带底色、基底色必须是不透明值）。

## 五、验证

- `vue-tsc -b`、`pnpm test`（199 passed / 26 files）、`pnpm build` 通过；
- 真实浏览器取 `getComputedStyle`，四个按钮的
  `background / border / color / fontWeight / fontSize / borderRadius / boxShadow` **唯一值均为 1 个**；
- 悬停色四个一致（`rgb(236,245,255)`）；逐个点击后把鼠标移开，底色回到纯白，无焦点残留；
- 键盘 Tab 依次聚焦四个按钮：底色均为白，白色描边可见；
- 守卫测试反向验证：把任一按钮的 `header-btn` 去掉，测试立即失败。
