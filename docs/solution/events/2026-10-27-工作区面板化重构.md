# 工作区面板化重构（抽屉 → flex 三栏）

## 一、为什么推倒重来

前面几轮都在"修抽屉"：遮罩穿透、主区 padding 让位、关闭时宽度归零、窄屏遮罩降级……
每一个补丁都在和 `el-drawer` 的**模态语义**较劲。问题不在细节，在载具选错了：

| 需求 | `el-drawer` 的本职 | 我们要的 |
|---|---|---|
| 与主区并排 | 覆盖在页面上（fixed + append-to-body） | 占文档流、参与 flex 分配 |
| 主区可点 | 模态：遮罩 + 焦点锁定 | 非模态：随时可点 |
| 宽度可调 | `size` 内联宽度，无过渡 | 宽度过渡 + 拖拽 |
| 收起 | `translateX` 滑出 → 消失 | 收窄到图标条，入口常驻 |
| 窄屏 | 本来就是覆盖态 | 覆盖要带遮罩（唯一需要遮罩的场景） |

结论：**分栏不该用抽屉实现**。这是本次重构的唯一理由。

## 二、对标范式

| 参考 | 借鉴点 |
|---|---|
| VS Code | 侧栏 + 活动栏（Activity Bar）：折叠后保留 48px 图标条，图标点击展开；侧栏宽度可拖拽 |
| Slack / 飞书 | 顶部应用栏通栏，三栏各自有等高的 channel header，形成一条水平分隔线 |
| Notion | 内容列限宽居中（可读行长），而不是把容器限宽导致两侧露出底色 |

反面参考：任何"用 Modal/Drawer 拼分栏"的做法——最终都会长出一堆 `pointer-events: none`、
`padding` 让位、`size` 归零之类的补偿代码。

## 三、结构

```
.workspace-shell            (flex column, 100vh)
├── .app-header             通栏应用栏（渐变，横跨三栏）
└── .workspace-body          (flex row, 剩余高度)
    ├── <PanelShell side="left">    浮动宽度 420~720，折叠 48
    │     ├── .panel-rail     折叠态图标条（日志收集 / 历史工单）
    │     └── .panel-main     展开态：.panel-head(48) + .panel-body
    ├── <main .app-main>       flex: 1
    │     ├── .main-head      48px，与两侧 panel-head 等高
    │     └── <ChatWindow/>
    └── <PanelShell side="right">   560~820，折叠 48
          ├── .panel-rail     折叠态图标条（SSH 终端）
          └── .panel-main     展开态：.panel-head(48) + TerminalPanel
```

关键实现：

- **PanelShell.vue**：唯一的面板外壳（标题栏 / 收起按钮 / 折叠图标条 / 边缘拖拽手柄）。
  内容是 `v-show` 而非 `v-if`——折叠一次不该销毁 xterm 与 SSH 会话。
- **宽度**：`style.width = open ? width : 48`，`transition: width .3s`；
  折叠时内容 `opacity: 0` 快速淡出，避免"文字被切一半"。
- **折叠入口常驻**：`rail` 插槽由 App 注入图标按钮，与 VS Code 活动栏一致；
  这正是之前"左边收窄成一个按钮、但最后没有这个按钮"要的东西。
- **窄屏降级**（<1024，或 1024~1440 双开放不下）：面板 `position: absolute` 覆盖 +
  `.panel-scrim` 遮罩，点遮罩收起。这是**唯一**还会出现遮罩的场景。

## 四、删掉的补偿代码

| 删除项 | 原因 |
|---|---|
| `.workspace-shell` 的 `padding-left/right` 让位与过渡 | 面板在文档流里，flex 自动分配 |
| `modal-class="drawer-push-overlay"` 及 CSS | 不再有遮罩穿透问题 |
| `drawer-resize-handle` 及其定位 | 手柄由 PanelShell 提供 |
| `resolveWorkspaceLayout` 关闭态返回 0 宽的补丁 | 面板宽度与开合解耦后不需要了 |
| ChatWindow 内两个 `el-drawer` | 终端与历史工单迁到 App 左右栏 |
| `showTerminalReplayDialog` 本地状态 | 回放状态放 store，两侧都能触发 |
| `styles/workspace-drawer.css` | 更名为 `workspace-panel.css`，只留描述表兜底与终端贴边 |

## 五、对抗性审查

| 场景 | 结论 |
|---|---|
| 折叠再展开日志面板 | 内容 `v-show` 保留，不重新 probe、不断 SSH（浏览器验过 DOM 常驻） |
| 折叠时终端 fit | 宽度收窄到 48px 期间 xterm 会重排一次，fit 已合并 60ms，过渡结束后稳定 |
| 拖拽与过渡冲突 | 拖拽中加 `is-resizing` 关掉 `transition`，逐帧跟手 |
| 窄屏两面板同时开 | 各自 560px 覆盖、互不重叠，中间留遮罩带；点遮罩先收右侧（上层） |
| 中央标题栏挤压 | 标题 `nowrap` + 工单标题 `ellipsis`，460px 宽仍可读 |
| 单元测试旧断言 | 两条"抽屉"用例改写为"不再自带抽屉外壳"与"工具条只有刷新进度" |
