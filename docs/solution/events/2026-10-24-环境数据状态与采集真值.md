# 环境数据卡片：状态改为描述"是否真有数据"，并消除空色块

## 一、现象

客户环境里「环境数据（已采集）」后面挂着一个绿色空心小方块，点开后正文却写
「集群数据暂未采集」——标题说已采集，正文说没采集。

## 二、根因

### 1. 状态看的是"请求成功"，不是"有数据"

`stores/chat.ts` 的 `collectEnvironmentData()` 里：

```ts
const res = await environmentApi.getContext(caseId)
environmentContext.value = res.data
// ……按 env_info / alert_logs / task_logs 是否为空写好了 collectionProgress
collectionState.value = 'success'   // ← 只要没抛异常就置 success
```

`collectionState = 'success'` 的真实语义是「采集接口调用成功」，而组件把它当成
「已经采到数据」直接显示。后端在未采集时会返回 `{ hci_version: '未知', cluster_name: '未知',
host_count: '未知' }` 这种占位对象——对象非空，但一个有效值都没有。

### 2. 那个绿方块是"只有图标没有文字"的标签

```html
<el-tag v-if="collectionState === 'success'" size="small" type="success" effect="plain" :icon="CircleCheck" />
```

`el-tag` 没有默认插槽内容，只剩一个 16px 的图标和内外边距；图标在 plain 主题下颜色很淡，
肉眼看到的就是一个空心绿框，用户无法理解它代表什么。

## 三、修法

### 状态按"数据真值"派生

```ts
function hasValue(v: unknown): boolean {
  if (v === null || v === undefined) return false
  if (typeof v === 'string') return v.trim() !== '' && v !== '未知'
  if (Array.isArray(v)) return v.length > 0
  return true
}

const hasUsableData = computed(() => {
  const ctx = chatStore.environmentContext
  if (!ctx) return false
  if (ctx.env_info && Object.keys(ctx.env_info).some((k) => hasValue(ctx.env_info[k]))) return true
  return (ctx.alert_logs?.length ?? 0) > 0 || (ctx.task_logs?.length ?? 0) > 0
})

const displayState = computed(() => {
  if (collectionState.value === 'collecting') return 'collecting'
  if (collectionState.value === 'error') return 'failed'
  return hasUsableData.value ? 'collected' : 'empty'   // idle + 有数据 = 已采集
})
```

关键点：

1. **`'未知'` 必须当作空值**：它是后端"没采到"的占位，不是数据；
2. **`idle` 也要按数据判断**：`collectionState` 是内存态，页面刷新后会回到 `idle`，
   若此时页面已有数据，简单按状态映射会把"已采集"错显示成"暂无数据"；
3. **告警/任务非空同样算采到内容**，避免"集群版本未知但告警已采到"被判成无数据。

### 状态标签必须带文字

```html
<span class="card-title">环境数据</span>
<el-tag size="small" :type="stateTag.type" effect="plain">
  <el-icon><component :is="stateTag.icon" /></el-icon>
  {{ stateTag.label }}
</el-tag>
```

| displayState | 标签 | 含义 |
|---|---|---|
| `collected` | 绿色 `已采集` | 至少有一块真实数据 |
| `collecting` | 黄色 `采集中` | 正在请求 |
| `failed` | 红色 `采集失败` | 请求异常 |
| `empty` | 灰色 `暂无数据` | 请求成功但全是占位值 |

标题里的「（已采集）」删掉：状态已经由彩色标签表达，标题再写一遍会重复，
而且写死之后必然和真实状态脱节。

## 四、验证

- `EnvironmentSummary.state.spec.ts`（6 例）：全占位字段不再显示「已采集」、有版本显示「已采集」、
  只有告警也算有数据、刷新后 idle 仍正确、采集中/失败独立、标签必须带文字；
- `pnpm test` 205 passed / 27 files，`vue-tsc -b`、`pnpm build` 通过；
- 浏览器并排渲染五种状态：标签均「图标 + 文字」，宽度 52~64px，无空色块，控制台无报错。
