# 技能与管理台页面交互一致性优化实施计划

## 2. 前端管理页面 Dialog 样式与交互优化

### 2.1 SOP 管理页面 ([SopManageView.vue](file:///mnt/d/aihci/hci-troubleshoot-platform/frontend/admin/src/views/SopManageView.vue))
- 定义 `const editFullscreen = ref(false)`，并在 `openEditDialog()` 时重置为 `false`。
- 升级编辑弹窗的 `<el-dialog>` 标签：
  - 使用 `class="premium-dialog"` 和 `:fullscreen="editFullscreen"`，设置宽度 `width="90%"`。
  - 使用 `#header` 插槽，添加类似查看弹框的自定义标题栏，内置 FullScreen 按钮切换。
- **一致性优化**：将 filter-card 中的分类过滤框由 `el-input` 升级为 `el-select` 下拉选择框（复用已引入的 `categoryOptions`），以与 KbdReviewView.vue 及其他页面的过滤样式完全一致。

### 2.2 KBD 管理页面 ([KbdReviewView.vue](file:///mnt/d/aihci/hci-troubleshoot-platform/frontend/admin/src/views/KbdReviewView.vue))
- 引入全局 `FullScreen` 图标。
- 定义 `const detailFullscreen = ref(false)` 和 `const editFullscreen = ref(false)`，并在打开弹窗时重置为 `false`。
- 升级详情弹窗 (`detailDialogVisible`)：
  - 添加 `class="premium-dialog"`、`:fullscreen="detailFullscreen"`，设定 `width="90%"`。
  - 添加自定义 header 插槽与全屏切换按钮。
- 升级编辑弹窗 (`editDialogVisible`)：
  - 添加 `class="premium-dialog"`、`:fullscreen="editFullscreen"`，设定 `width="90%"`。
  - 添加自定义 header 插槽与全屏切换按钮。

### 2.3 技能管理页面 ([SkillManageView.vue](file:///mnt/d/aihci/hci-troubleshoot-platform/frontend/admin/src/views/SkillManageView.vue))
- 将 `isFullscreen` 的默认值改为 `false`（原为 `true`）。
- 在 `openCreateDialog()` 和 `openEditDialog()` 时设置 `isFullscreen.value = false`。
- 在 `<el-dialog>` 标签上添加 `width="90%"`，以保证在非全屏模式下具备大视口（90%）显示，便于流畅编辑双栏内容。

## 3. 管理页面样式与交互一致性分析报告

以下是针对 KBD管理、SOP管理、工具管理、技能管理、Prompt管理 5个板块的深入对照与一致性优化：

| 模块 | 弹窗展示机制 | Markdown渲染/预览方案 | 过滤栏风格与组件选择 | 操作按钮列排版 |
|---|---|---|---|---|
| **工具管理** | `premium-dialog`，支持 fullscreen 切换。首开非全屏。 | 参数是纯 JSON 编辑，无 MD 预览。 | `el-select` (分类) + `el-input` (搜索)。 | 单行显示，文本链接样式。 |
| **SOP管理** | 查看弹窗：`premium-dialog` + 全屏切换；编辑弹窗：旧 `width="900px"`，**将升级为 `premium-dialog` + 全屏**。 | 决策树交互渲染，暂无通用 MD 渲染。 | 目前是 `el-input` 分类过滤。**将升级为与 KBD 一致的 `el-select` 下拉检索**。 | 单行显示，文本链接样式。 |
| **KBD管理** | 详情/编辑弹窗：旧固定宽度，**将全面升级为 `premium-dialog` + 全屏切换**。 | 使用 DOMPurify + marked 渲染。内联编辑和弹窗编辑分离。 | `el-select` (AI分类) + `el-input` (搜索)。 | 拥有 `.action-btn-group` 并排显示。 |
| **技能管理** | `skill-detail-dialog`，支持全屏切换。原默认全屏，**将改为默认非全屏，支持 90% 宽度**。 | 双栏实时预览：左侧 TextArea，右侧 Marked 渲染预览。 | `el-select` (分类筛选) + `el-input` (搜索)。 | 并排单行显示。 |
| **Prompt管理**| `premium-dialog`，支持 fullscreen 切换。首开非全屏。 | 支持双栏实时预览（Marked 渲染）。 | `el-select` (大模型类型) + `el-input` (搜索)。 | 并排单行显示。 |
