# 排障Agent可靠性改造阶段三（推理约束）与阶段四（评测闭环）实施计划

本计划旨在完成超融合排障 Agent 可靠性改造的最后两个阶段（阶段三与阶段四），实现大模型推理的结构化约束、前端思考过程折叠、无 LLM 开销的轻量级幻觉检测规则引擎、强制验证闭环、黄金工单评测集构建、FactStore 迁移至 PostgreSQL 以及 CI 回归评测门禁。

## 用户审查

> [!IMPORTANT]
> 1. **CoT 思考过程外显与前端折叠 (T3-3)**：系统将在 InvestigationAgent 的提示词中强制 LLM 在输出任何回答前使用 `<reasoning>` 标签包裹其思考过程（包含已收集证据、假设支撑/反对、置信度评估、下一步行动）。前端 `MessageBubble.vue` 将识别此标签，并将其中间推理过程自动折叠在 Element Plus 的 Collapse 组件中展示，从而避免冗长的思考干扰用户阅读。
> 2. **轻量版幻觉检测器 (T3-4)**：新增 `HallucinationDetector` 服务，在不增加二次 LLM 调用开销（延迟 < 100ms）的前提下，通过规则引擎检测：引用未执行的工具（幻觉工具）、包含强声明但缺乏不确定性修饰词（过度自信）以及数字事实在工具输出中无匹配来源（数字幻觉）。检测到高风险时会追加警告，并在报告生成前触发 Agent 重新生成。
> 3. **修复后强制验证 (T3-5)**：在 React 循环中引入状态监控。如果 Agent 执行了写操作工具（`risk_level >= 2`），在其宣布故障修复/完成排障前，系统强制拦截，要求其必须先调用对应的验证工具（如 `get_active_alerts` / 状态查询等）。若跳过则自动弹回给 LLM 提示词进行补救。
> 4. **数据库结构迁移与 FactStore 持久化 (T4-3)**：FactStore 的底层数据源将从纯 Redis 缓存迁移至 PostgreSQL（新增 `fact` 与 `claim_evidence_link` 表），Redis 保留为 5 分钟的缓存。此改造将确保工单关闭后 30 天内仍可对所有排障结论进行完整的证据链溯源。

## 开放性问题

1. **S3/S4 阶段命名映射**：
   在现有的 `diagnostic_stage` 流程中，`S2` 对应 "S2 - 假设生成"，`S3` 对应 "S3 - 证据验证"，`S4` 对应 "S4 - 根因确认"。
   计划中要求 "S3 假设生成阶段" 使用 `ReasoningOutput` 结构化 JSON，"S4 验证阶段" 使用 `ClaimVerification` 结构化 JSON。
   我们将在代码中兼容两个映射：
   - 阶段为 `S2`（或 `S3`）：输出强制符合 `ReasoningOutput` Schema；
   - 阶段为 `S4`（或 `S3` 作为验证终态）：输出强制符合 `ClaimVerification` Schema。
   我们通过在 `ReactEngine.execute` 中引入 `response_schema` 参数，在 Agent 端调用时按需注入，实现通用化的 Schema 约束与解析。

### 4. 轻量级幻觉检测器 (T3-4)

#### [NEW] [hallucination_detector.py](file:///mnt/d/aihci/hci-troubleshoot-platform/backend/agent-service/app/services/hallucination_detector.py)
- 实现 `HallucinationDetector` 类：
  - `phantom_tool_reference`：匹配 LLM 文本中的工具名称（从注册表中），如果当前会话未执行过则标记幻觉。
  - `overconfident_claim`：提取强声明（如 "已确认故障根因是"），检查是否缺乏不确定性词汇修饰。
  - `ungrounded_number`：提取百分比、GB、ms 等数值事实，与当前 session 执行过的所有工具的 stdout/stderr 结果进行交叉匹配。
- 探测到幻觉时返回结构化报告，并在报告中标记幻觉类别。

#### [MODIFY] [react_engine.py](file:///mnt/d/aihci/hci-troubleshoot-platform/backend/agent-service/app/adapters/agents/htp/react_engine.py)
- 在生成 final text 响应前运行 `HallucinationDetector`。如果发现中高风险幻觉，在最终回复尾部拼接醒目的 `*待验证*` 幻觉风险警告。

#### [MODIFY] [investigation_agent.py](file:///mnt/d/aihci/hci-troubleshoot-platform/backend/agent-service/app/adapters/agents/htp/investigation_agent.py)
- 在最终生成诊断报告前运行 `HallucinationDetector`。如果存在高风险幻觉结论，清空该输出并触发 Agent 的 Re-run（重试生成，最大 1 次），若仍然检测出幻觉，则输出内容并附带幻觉警告。
