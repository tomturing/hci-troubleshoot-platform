# 2026-11-17 云端 terminal_bridge 日志直传补全（不依赖浏览器）

## 背景与需求

生产/云端形态下 terminal_bridge 以 `--mode=cluster` 跑在 K3s Pod 里，浏览器只通过同源
`/terminal-bridge` 连它。原有日志落库只有一条路：bridge 把结构化日志经 WS 推给浏览器，
前端再批量 `POST /api/bridge-logs` 由 conversation-service 落 `bridge_execution_logs`。

2026-11-17 在 dev 实测暴露三个缺口：

1. **直传通道从未启用**。`/status` 长期显示 `log_upload.enabled=false`、`instance=""`：
   唯一的令牌来源是前端 `bridge_log_token`，云端桥没有浏览器发它，worker 永不启动。
2. **插件下发的 `exec.*` 日志零入库**。`bridge_execution_logs` 中 `exec.request/exec.start/exec.done`
   各 38 条、最新停在 07-30：插件下发由 case-service 直连 bridge 发起（`ACLI_PLUGIN_BRIDGE_URL`），
   浏览器不在链路里，没有订阅者时日志只进环形缓冲与本地文件。
3. **真实事件被归属校验拒收**。同一天 07:05 的 `session.created` / `ssh.connected` /
   `acli_sync.*` 在库中查无，conversation-service 日志显示
   `bridge_log_ownership_forbidden case_id=Q2026101409999 client_id=a556827b…`，
   批次 `accepted=0 / forbidden=4`：浏览器身份对该工单没有 `data_access`，
   而桥日志本身属于平台运行证据，不该由浏览器身份决定能否入库。

## 根因

| 缺口 | 直接原因 | 代码位置 |
|---|---|---|
| 直传不启动 | 只有 WS 下发 `bridge_log_token` 一条入口，无部署期自举 | `terminal_bridge/log_uploader.go` `configure()` |
| 服务端下发日志丢失 | 下发由 case-service 发起，浏览器不在链路上，无订阅者时分发日志只落本地 | `terminal_bridge/main.go` `case "ssh_exec_process"` |
| 云端令牌无所指 | direct 通道令牌绑定单一 `case_id`，一个桥服务多工单时无法表达 | `backend/conversation-service/app/routes/bridge_logs.py` `ingest_bridge_logs_direct` |
| 崩溃窗口丢失 | 进程被杀时最后一段日志只写本地文件，既不在 outbox 也没进库 | `terminal_bridge/log_uploader.go` |
| 实例头被网关丢弃 | 网关 direct 代理只透传 `X-Bridge-Upload-Token` | `backend/api-gateway/app/routes/bridge_logs.py` |

## 修复

### 1. 桥侧自举（`terminal_bridge/log_uploader.go`）

- `bootstrapFromEnv()`：读 `HCI_BRIDGE_LOG_UPLOAD_ENDPOINT` + `HCI_BRIDGE_LOG_UPLOAD_TOKEN`，
  齐全即以实例号调用 `configureWithSource(..., "env")`，与浏览器下发共用同一个 worker。
- `/status` 的 `log_upload` 新增 `source` 字段（`env` / `ws`）：排障第一眼即可判断
  "直传到底有没有被启用、是谁启用的"。
- 上报请求新增 `X-Bridge-Instance-Id` 头，服务端据此把批次绑定到具体实例。

### 2. 崩溃窗口补传（水位）

- 每次批次成功后才把该批最大 `seq` 原子写入 `bridge-log-uploaded-<实例>.seq`（临时文件 + rename）。
- 进程启动时 `seedFromLocalLogs()` 扫描最近 N 个 `bridge-*.log`，只把 `seq > 水位` 的条目
  回灌队列；后端按 `event_id` 唯一约束幂等，重复补传不产生重复行。
- 默认只扫 2 个文件、最多 5000 条（`HCI_BRIDGE_LOG_SEED_FILES` / `_SEED_ENTRIES`），
  避免启动阶段全量扫盘。
  - **订正（2026-11-21，L1 之后）**：上面这句只描述首版行为。L1 把这两个旋钮改为
    **单轮预算**——扫描范围是全量文件（含轮转件与当前文件），预算用尽记进度、下一轮
    继续，直到水位之后的历史全部进管道。`DefaultSeedMaxFiles=2` / `DefaultSeedMaxEntries=5000`
    因此不再是"只扫 2 个文件、最多 5000 条"的硬窗口。

### 3. 服务端接受"集群桥身份"（`backend/conversation-service`）

- `POST /api/bridge-logs/direct` 在 HMAC 校验前先判 `X-Bridge-Upload-Token` 是否等于
  `INTERNAL_API_TOKEN`（`hmac.compare_digest`）：相等则走 `_ingest_direct_internal`。
- 内部模式**不绑单、不做工单归属校验**，按每条日志自带的 `case_id` 归档，
  `user_id` 固定为 `bridge:<实例前12位>`；条目实例号与请求头不一致即丢弃（防令牌被复制）。
- 缺 `case_id` 的生命周期事件（`bridge.startup` / `bridge.connected`）落到
  `bridge-<实例前8位>` 哨兵号：不与真实工单混淆，但保证"桥起不来"这类第一证据不丢。

### 4. 网关透传实例头（`backend/api-gateway`）

`/api/bridge-logs/direct` 代理补传 `X-Bridge-Instance-Id`；仍不注入、不信任任何 `X-Client-ID`。

### 5. 部署（`deploy/helm/hci-platform`）

- `terminalBridge.logUpload.enabled`（默认 `true`）：注入端点（默认
  `http://api-gateway:<apiGateway.port>/api/bridge-logs/direct`）、令牌（Secret `hci-secrets`
  的 `INTERNAL_API_TOKEN`）、补传参数。
- NetworkPolicy 新增到 `api-gateway:<port>` 的 egress：缺这条时直传在 netpol 层被静默丢弃，
  表现为"队列只涨不降、库里零桥日志"。
- 四个新变量登记 `deploy/config/config-contract.yaml` 的 `helm_only_runtime`，防止
  `config-contract-check` 失败。

## 安全边界

- 内部令牌只存在于集群 Secret，不出集群；桌面模式未配置该变量时行为与历史一致（空操作）。
- 该通道只写"日志"这一张表，不能下发命令、不能读取工单内容。
- 实例绑定 + 逐条实例号校验，令牌被复制到别的桥无法写入。
- 归属校验仍保留在浏览器回采通道（`/api/bridge-logs`）：客户身份写他人真实工单日志仍被拒。

## 验证

- `terminal_bridge/log_uploader_bootstrap_test.go`：未配置时零动作、注入后 `source=env`、
  水位过滤只补未上传区间、水位单调递增。
- `backend/conversation-service/tests/unit/test_bridge_logs.py::TestDirectInternalBridgeUpload`：
  按条目 `case_id` 归档、无工单落实例哨兵号、跨实例条目拒绝、错误令牌仍 401。
- Helm unittest：默认注入上传变量、关闭时不注入、netpol egress 数量与目标端口。
- 线上判据：`/status` 的 `log_upload.source == "env"` 且 `queued` 能被消化；
  `bridge_execution_logs` 中 `exec.*` / `acli_sync.*` 持续有当日数据。

## 遗留

- 无工单日志只落 `bridge-*` 哨兵号，管理端尚无"按桥实例查日志"的入口，当前需按 SQL/日志平台检索。
- 桥侧 `outbox` 与水位文件都在同一 PVC；PVC 写满时先丢 outbox（`dropped` 计数可见），
  需要配合 `terminal-bridge-data` 容量告警一起看。
