## 1. 接口概述

### 1.1 服务端口

| 服务 | 端口 | 说明 |
|------|------|------|
| API Gateway | 8000 | 统一入口 |
| Case Service | 8001 | 工单管理 |
| Conversation Service | 8002 | 对话管理 |
| Agent Service | 8003 | AI 推理 |
| KB Service | 8004 | 知识库 |
| Scheduler Service | 8005 | 调度 |
| Eval Service | 8006 | 评估 |

### 1.2 通用约定

#### 请求头

```http
Content-Type: application/json
X-Client-ID: <client_id>
traceparent: <trace_id>    # W3C Trace Context
```

#### 响应格式

**成功**:
```json
{
  "code": 0,
  "message": "success",
  "data": { ... },
  "trace_id": "00-xxx-xxx-01"
}
```

**错误**:
```json
{
  "code": 4001,
  "message": "Resource not found",
  "trace_id": "00-xxx-xxx-01"
}
```

## 2. Case API

### 2.1 创建工单

```
POST /api/cases
```

**请求体**:
```json
{
  "title": "虚拟机启动失败",
  "description": "虚拟机无法启动",
  "assistant_type": "htp-agent"  // 可选
}
```

**响应**:
```json
{
  "code": 0,
  "data": {
    "case_id": "Q20260522001",
    "status": "created",
    "assistant_type": "htp-agent"
  }
}
```

### 2.2 查询工单列表

```
GET /api/cases?status=confirmed&page=1&page_size=20
```

### 2.3 查询工单详情

```
GET /api/cases/{case_id}
```

### 2.4 确认工单

```
PUT /api/cases/{case_id}/confirm
```

### 2.5 关闭工单

```
PUT /api/cases/{case_id}/close
```

## 3. Conversation API

### 3.1 发送消息（SSE 流式）

```
POST /api/conversations/{id}/message
```

**请求体**:
```json
{
  "content": "虚拟机无法启动",
  "assistant_type": "ops-agent"  // 可选，动态切换助手
}
```

**响应**: SSE 流

```
data: {"type": "text_chunk", "content": "您好..."}

data: {"type": "stage_update", "stage": "S1"}

data: {"type": "interactive_request", "request_id": "req-xxx", "kind": "sop_step", ...}

data: {"type": "done"}
```

### 3.2 查询消息历史

```
GET /api/conversations/{id}/messages?page=1&page_size=50
```

### 3.3 提交交互响应

```
POST /api/conversations/{id}/interactive-response
```

**请求体**:
```json
{
  "request_id": "req-xxx",
  "outcome": {"outcome": "selected", "optionId": "1"}
}
```

### 3.4 提交评分

```
POST /api/conversations/{id}/evaluate
```

**请求体**:
```json
{
  "rating": 5,
  "feedback": "问题已解决"
}
```

## 4. Agent Service API

### 4.1 流式推理

```
POST /v1/agent/stream
```

**请求体**:
```json
{
  "assistant_type": "ops-agent",
  "session_id": "conv-xxx",
  "case_id": "Q20260522001",
  "user_id": "user-xxx",
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "..."}
  ],
  "env_context": {"active_alerts": [...], "failed_tasks": [...]}
}
```

**响应**: SSE 流

```
data: {"type": "text_chunk", "content": "..."}

data: {"type": "stage_update", "stage": "S2", "metadata": {}}

data: {"type": "interactive_request", "request_id": "req-xxx", ...}

data: {"type": "escalation", "reason": "..."}

data: {"type": "done"}

data: {"type": "error", "message": "..."}
```

### 4.2 提交交互响应

```
POST /v1/agent/interactive-response
```

**请求体**:
```json
{
  "acp_session_id": "conv-xxx",
  "request_id": "req-xxx",
  "outcome": {"outcome": "selected", "optionId": "1"}
}
```

### 4.3 恢复事件流

```
GET /v1/agent/resume-stream/{session_id}
```

### 4.4 健康检查

```
GET /v1/agent/health
```

## 5. KB Service API

### 5.1 知识检索

```
POST /api/kb/search
```

**请求体**:
```json
{
  "query": "虚拟机启动失败",
  "top_k": 5,
  "category_id": "虚拟机-003"  // 可选
}
```

**响应**:
```json
{
  "code": 0,
  "data": {
    "chunks": [
      {
        "chunk_id": "xxx",
        "content": "...",
        "score": 0.85,
        "source": "kbd_entry:xxx"
      }
    ]
  }
}
```

### 5.2 SOP 匹配

```
POST /api/kb/sop/match
```

**请求体**:
```json
{
  "query": "虚拟机启动失败"
}
```

### 5.3 分类列表

```
GET /api/kb/categories
```

### 5.4 带步骤案例检索（CDD）

`InvestigationAgent` 在 KBD 轨道使用该接口获取候选案例和结构化排查步骤，用于案例差异诊断。

```
POST /api/kbd/search-cases-with-steps
```

**请求体**:
```json
{
  "query": "虚拟机启动失败",
  "category_id": "虚拟机-003",
  "top_k": 15,
  "similarity_threshold": 0.2
}
```

**响应**:
```json
{
  "cases": [
    {
      "id": "case-001",
      "name": "虚拟机开机失败：Redis OOM",
      "category_id": "虚拟机-003",
      "similarity": 0.87,
      "root_cause": "Redis 内存不足导致任务失败",
      "solution": "清理 Redis 或扩容内存后重试",
      "steps": [
        {
          "tool_name": "acli_run",
          "description": "检查失败任务详情",
          "expected_pattern": "任务失败原因包含 OOM 或 Redis"
        }
      ]
    }
  ]
}
```

### 5.5 SOP 决策树查询

`GET /api/sop/{id}/tree` 直接返回 `SOPNode` 根节点，不再额外包裹 `document_id`。

```
GET /api/sop/{id}/tree
```

**响应**:
```json
{
  "node_id": "n-1",
  "name": "虚拟机开机失败排查",
  "level": 1,
  "prerequisites": [],
  "diagnosis": null,
  "solution": null,
  "children": []
}
```

## 7. Environment API

### 7.1 上传环境数据

```
PUT /environments/case/{case_id}/type/{env_type}
```

**路径参数**:
- `case_id`: 工单 ID
- `env_type`: `alert` | `task` | `environment`

**请求体**:
```json
{
  "data": [
    {"name": "vm-web-01", "status": "shut_off", ...}
  ],
  "collected_at": "2026-05-22T10:00:00Z"
}
```

## 9. SSE 事件类型

### 9.1 AgentEvent 类型

| 类型 | 字段 | 说明 |
|------|------|------|
| `text_chunk` | `content` | 文本流块 |
| `stage_update` | `stage`, `metadata` | 阶段更新 |
| `interactive_request` | `request_id`, `kind`, `title`, `options` | 交互请求 |
| `escalation` | `reason`, `context` | 人工升级 |
| `done` | - | 流结束 |
| `error` | `message` | 错误 |

### 9.2 interactive_request 详情

```json
{
  "type": "interactive_request",
  "request_id": "req-xxx",
  "acp_session_id": "conv-xxx",
  "kind": "sop_step",
  "title": "检查虚拟机状态",
  "prompt": "请选择要执行的操作",
  "options": [
    {"optionId": "1", "name": "查看详情"},
    {"optionId": "2", "name": "执行命令"}
  ],
  "custom_input": true,
  "metadata": {}
}
```

| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
