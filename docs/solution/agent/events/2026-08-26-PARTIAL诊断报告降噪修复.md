# PARTIAL 诊断报告降噪修复

## 问题

多 KBD 场景中，至少一个候选已满足全部必要信号、但其他候选尚未排除时，诊断级别为 `PARTIAL`。旧实现先生成“证据不足”报告，再在前面拼接“部分证据成立”文案，造成重复结论、重复证据和内部状态信息干扰用户判断。

## 处理

- `PARTIAL` 使用独立报告模板，只输出一个主结论。
- 已命中案例只展示案例标识和对应现场证据，不输出根因或解决方案。
- 其他候选集中展示为“仍需排除的候选”，内部错误标识压缩为用户可理解的原因。
- 原始错误、执行标识和完整输出继续保留在审计数据与链路日志中。
- `INCONCLUSIVE`、`NO_MATCH` 和 `DEFINITIVE` 继续使用各自原有模板，Conclusion Gate 判定不变。

## 验证

新增回归测试确保 PARTIAL 最终报告只有一个结论标题、不包含“证据不足”模板、不泄漏根因/方案，并过滤内部 `expert_*` 错误标识。
