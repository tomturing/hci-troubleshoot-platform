## 一、修复目标与原则

### 1.1 目标

闭环 PR #611 遗留的 2 个阻断级、10 个严重级、8 个一般级问题，使"v2 信号契约拍平 + v1 彻底清理"在**数据迁移、运行时、前端、契约文案、文档**五个层面完全自洽。

### 1.2 原则

- **单一事实来源（SSOT）**：字段名在契约（`acquirer_args.py`）、抽取（`extract_signals.py`）、运行时（`kbd_differential.py`）、前端（`KbdReviewView.vue`）、迁移（`010`）、文档六处一致。
- **迁移幂等且无损**：迁移 010 必须对 v2 对象正确遍历、按工具分支落位、不丢字段、可重跑。
- **不破坏已合并契约**：不改 `acquirer_args.py` 的字段集（已稳定），只修字段名引用的一致性与死代码。
- **最小改动**：每个问题定点修复，不扩大重构面。
